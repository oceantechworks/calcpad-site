1. Ce que vous pouvez faire avec CalcPad

CalcPad vous permet principalement de faire les opérations suivantes :

  • L’utiliser comme une calculatrice classique
  • Créer et enregistrer les formules que vous utilisez souvent
  • Rappeler une formule enregistrée et calculer en saisissant seulement les variables
  • Enregistrer les nombres que vous utilisez souvent comme préréglages
  • Copier les résultats de calcul et les expressions
  • Réutiliser des valeurs depuis l’historique de copie
  • Calculer avec des fonctions de base

2. Utiliser CalcPad comme une calculatrice classique

Sur l’écran principal de CalcPad, vous pouvez saisir des nombres et des opérateurs comme avec une calculatrice classique.

Utilisation de base

  1. Saisissez un nombre.
  2. Saisissez un opérateur comme +, −, × ou ÷.
  3. Touchez = pour afficher le résultat.

Les calculs restent affichés sous forme de journal. Vous pouvez donc continuer à calculer tout en vérifiant les opérations récentes.

3. Créer une formule

L’une des principales fonctions de CalcPad est de créer et d’enregistrer les formules que vous utilisez souvent.

Par exemple, vous pouvez enregistrer des formules comme celles-ci :

Prix unitaire × Quantité
Taux horaire × Heures travaillées + Prime fixe
Recettes − Dépenses
Poids ÷ Taille ^ 2

Après avoir enregistré une formule, vous pouvez la rappeler plus tard et calculer en saisissant seulement les valeurs nécessaires.

Étapes de création d’une formule

  1. Saisir les informations de base
  2. Vérifier les réglages d’affichage du résultat
  3. Définir les variables
  4. Créer la formule
  5. L’enregistrer

3.1 Saisir les informations de base

Commencez par saisir le nom de la formule.

Choisissez un nom facile à reconnaître lorsque vous consulterez plus tard la liste des formules.

3.2 Vérifier les réglages d’affichage du résultat

Vous pouvez ajuster la façon dont le résultat du calcul est affiché.

  • Libellé du résultat : le nom utilisé pour afficher le résultat. Si vous le laissez vide, il sera affiché comme « Résultat ».
  • Décimales : le nombre de décimales à afficher dans le résultat.
  • Arrondi : la méthode utilisée pour arrondir le résultat au nombre de décimales choisi (arrondir / arrondir vers le bas / arrondir vers le haut).

Par exemple, vous pouvez masquer les décimales pour les calculs de prix, ou les afficher pour les calculs de ratios.

3.3 Définir les variables

Une variable est une valeur que vous saisissez à chaque exécution d’une formule.

Par exemple, dans la formule suivante, Prix unitaire et Quantité sont des variables.

Prix unitaire × Quantité × 1,1

Lorsque vous exécutez la formule, saisissez les valeurs de Prix unitaire et Quantité, puis CalcPad calcule le résultat.

Ajouter une variable

Lorsque vous ajoutez une variable, saisissez les informations suivantes :

  • Type : nombre / pourcentage (%)
  • Nom de variable : le nom de la variable, par exemple Prix unitaire ou Quantité.
  • Valeur initiale : saisissez-la si vous voulez définir une valeur par défaut. Vous pouvez modifier cette valeur à chaque calcul.
  • Clé (a-z) : la lettre utilisée dans la formule à la place du nom de la variable.

3.4 Créer la formule

Créez la formule proprement dite à l’aide des variables.

Exemple :

a : Prix unitaire
b : Quantité

a × b × 1,1

Grâce aux variables, vous pouvez répéter le même calcul en ne saisissant que les valeurs qui changent.

3.5 Créer une formule avec des fonctions

Avec PRO, vous pouvez aussi utiliser les fonctions de base dans vos formules.

max(Ventes 1, Ventes 2, Ventes 3)
|Montant prévu - Montant réel|
round(Prix unitaire × Quantité)

Les fonctions permettent de créer des formules incluant des valeurs maximales, des valeurs minimales, des écarts, des arrondis, et plus encore.

Lorsque vous utilisez des fonctions trigonométriques, vous pouvez définir l’unité d’angle (DEG / RAD). Cette unité d’angle s’applique uniquement à cette formule.

4. Utiliser une formule enregistrée

Les formules enregistrées peuvent être sélectionnées et utilisées depuis la liste des formules.

Comment utiliser une formule

  1. Ouvrez la liste des formules avec le bouton f(x) du clavier de la calculatrice.
  2. Sélectionnez la formule que vous voulez utiliser.
  3. Saisissez les valeurs des variables affichées.
  4. Lorsque toutes les valeurs nécessaires sont saisies, le résultat s’affiche.

Exemple : Prix unitaire × Quantité × 1,1

Formule enregistrée :

Prix unitaire × Quantité × 1,1

Valeurs saisies lors de l’exécution :

[Prix unitaire] = 1 200
[Quantité] = 3

Résultat :

[Résultat] = 3 960

Même si vous utilisez souvent la même formule, vous n’avez qu’à saisir les valeurs des variables à chaque fois.

5. Utiliser les préréglages

Les préréglages vous permettent d’enregistrer les nombres que vous utilisez souvent.

Par exemple, enregistrer des taux de taxe, des frais, des prix unitaires courants ou des coûts fixes peut réduire la saisie manuelle.

Exemples de préréglages

Libellé Valeur
TVA 20% 0,2
Frais 330
Forfait de base 980
Taux horaire 1 500

5.1 Utiliser un préréglage

  1. Touchez le bouton PRE du clavier de la calculatrice pour ouvrir la feuille des préréglages.
  2. Touchez le préréglage que vous voulez saisir.

5.2 Ajouter, modifier ou supprimer des préréglages

  • Vous pouvez ajouter un préréglage avec le bouton + en haut à droite de la feuille des préréglages.
  • Vous pouvez modifier ou supprimer un préréglage depuis le menu à trois points situé à droite de chaque préréglage.

6. Utiliser COPY

CalcPad vous permet de copier les résultats de calcul et les lignes du journal.

6.1 Copier le dernier résultat de calcul

Touchez le bouton COPY pour copier le dernier résultat de calcul.

Par exemple, si le résultat suivant est affiché :

1 200 × 5 × 80%
= 4 800

Touchez COPY pour copier 4 800.

Vous pouvez ensuite coller la valeur copiée avec PASTE ou l’enregistrer comme préréglage.

6.2 Sélectionner et copier une ligne du journal

Appuyez longuement sur une ligne du journal affichée à l’écran pour la sélectionner.

Lorsqu’une ligne est sélectionnée, touchez COPY pour copier l’expression ou la valeur de cette ligne.

Par exemple, si ce journal est affiché :

1 200 × 5 × 80%
= 4 800

Sélectionnez la ligne de l’expression pour copier l’expression, ou la ligne du résultat pour copier le résultat.

7. Utiliser PASTE

PASTE insère dans le champ de saisie la valeur ou l’expression copiée le plus récemment.

Comment utiliser PASTE

  1. Copiez une valeur ou une expression avec COPY.
  2. Déplacez le curseur à l’endroit où vous voulez coller.
  3. Touchez PASTE.

C’est utile lorsque vous voulez réutiliser un résultat copié dans un autre calcul.

Retour à la table des matières

8. Utiliser HISTORY

Appuyez longuement sur le bouton PASTE pour ouvrir la feuille de l’historique de copie.

L’historique de copie conserve les valeurs et expressions que vous avez copiées auparavant.

Ce que vous pouvez faire avec HISTORY

  • Sélectionner un élément de l’historique et le coller
  • Enregistrer une valeur de l’historique comme préréglage
  • Copier un élément de l’historique vers le presse-papiers du système
  • Supprimer les éléments inutiles de l’historique

9. Utiliser les fonctions (fonction PRO)

Avec PRO, vous pouvez utiliser les fonctions et constantes de base.

Les fonctions peuvent être utilisées sur l’écran de calculatrice classique et dans l’éditeur de formules.

Ouvrir le clavier de fonctions

Sur l’écran de calculatrice classique, touchez le bouton Func en haut du clavier pour ouvrir le clavier de fonctions.

Le clavier de fonctions permet de saisir des racines carrées, des valeurs absolues, des fonctions trigonométriques, des logarithmes, des fonctions d’arrondi, des valeurs maximales, des valeurs minimales, et plus encore.

9.1 Unités d’angle

Les fonctions trigonométriques comme sin, cos et tan utilisent une unité d’angle.

CalcPad prend en charge les unités d’angle suivantes :

Affichage Signification
DEG Degrés
RAD Radians

L’unité d’angle sélectionnée sur l’écran de calculatrice classique est enregistrée comme réglage de la calculatrice classique.

Dans l’éditeur de formules, l’unité d’angle est enregistrée pour chaque formule. Ainsi, modifier l’unité d’angle de la calculatrice classique ne change pas les résultats des formules enregistrées.

9.2 Fermer le panneau de fonctions après saisie

Le clavier de fonctions dispose d’un réglage permettant de se fermer automatiquement après la saisie.

Lorsque ce réglage est désactivé, le clavier de fonctions reste ouvert après la saisie d’une fonction. Lorsqu’il est activé, le clavier se ferme après la saisie d’une fonction.

Si vous voulez saisir plusieurs fonctions à la suite, il est pratique de garder ce réglage désactivé.

10. Liste des fonctions et exemples

Cette section présente les principales fonctions et constantes disponibles dans CalcPad.

10.1 Racine carrée : √

Calcule la racine carrée d’une valeur.

√(9)

Résultat :

3

C’est utile, par exemple, pour trouver la longueur du côté d’un carré à partir de son aire.

10.2 Valeur absolue : |x|

La valeur absolue traite un nombre comme une valeur toujours positive ou nulle.

|1200 - 1500|

Résultat :

300

C’est utile lorsque vous voulez afficher une différence ou une erreur sous forme de valeur positive.

Exemple : trouver l’écart entre un montant prévu et un montant réel

|Montant prévu - Montant réel|

Vous obtenez uniquement l’ampleur de l’écart, que le montant réel soit plus élevé ou plus faible.

10.3 Pi : π

Saisit pi.

π

C’est utile pour les calculs liés aux cercles.

Exemple : aire d’un cercle de rayon 5

π × 5 ^ 2

10.4 Nombre d’Euler : e

Saisit le nombre d’Euler.

e

Il est utilisé pour les calculs exponentiels et les logarithmes naturels.

10.5 e puissance x : e^x

Élève e à la puissance indiquée.

e^(2)

C’est utilisé dans les calculs avec des fonctions exponentielles.

10.6 Fonctions trigonométriques : sin / cos / tan

Ces fonctions servent aux calculs liés aux angles.

sin(30)

Lorsque l’unité d’angle est DEG, le résultat est :

0,5

Lorsque vous utilisez des fonctions trigonométriques, vérifiez que l’unité d’angle est bien réglée sur DEG ou RAD selon votre intention.

10.7 Logarithme décimal : log

log est le logarithme en base 10.

log(100)

Résultat :

2

10.8 Logarithme naturel : ln

ln est le logarithme en base e.

ln(e)

Résultat :

1

10.9 Arrondir : round

Arrondit une valeur décimale à l’entier le plus proche.

round(12,6)

Résultat :

13
round(12,4)

Résultat :

12

C’est utile lorsque vous voulez convertir des décimales en nombres entiers pour des montants, des quantités ou des calculs similaires.

10.10 Arrondir vers le bas : floor

Arrondit une valeur décimale vers le bas.

floor(12,9)

Résultat :

12

Utilisez cette fonction lorsque vous voulez toujours arrondir la partie décimale vers le bas.

10.11 Arrondir vers le haut : ceil

Arrondit une valeur décimale vers le haut.

ceil(12,1)

Résultat :

13

C’est utile pour les calculs comme le nombre de boîtes ou de lots nécessaires, où tout reste signifie qu’il faut en prévoir un de plus.

Exemple : nombre de boîtes nécessaires lorsqu’une boîte contient 6 articles

ceil(Quantité nécessaire ÷ 6)

Si la quantité nécessaire est 13 :

ceil(13 ÷ 6)

Résultat :

3

10.12 Minimum et maximum : min / max

min renvoie la plus petite valeur parmi plusieurs valeurs, et max renvoie la plus grande valeur.

min(240 ÷ 2, 138, 15 × 10)

Résultat :

120
max(240 ÷ 2, 138, 15 × 10)

Résultat :

150

min et max ne servent pas seulement à trouver la plus petite ou la plus grande valeur. Ils sont aussi utiles lorsque vous voulez définir une limite supérieure ou inférieure dans une formule.

10.13 Exemples avec min / max

Avec min et max, vous pouvez créer des formules qui empêchent une valeur de dépasser un certain montant, de descendre sous un certain montant, ou qui calculent seulement la partie au-dessus d’un seuil.

Exemple : ajouter uniquement la partie au-dessus d’un seuil

Vous pouvez utiliser max pour calculer uniquement la partie qui dépasse une certaine valeur.

Exemple : calcul d’une rémunération de livraison

  • La rémunération de base est 3 600
  • Jusqu’à 10 km, seule la rémunération de base est versée
  • Pour la distance au-delà de 10 km, ajouter 100 par km
3600 + 100 × max(0, Distance - 10)

Avec max(0, Distance - 10), le supplément est de 0 lorsque la distance est de 10 km ou moins. Seule la distance au-delà de 10 km est ajoutée.

Exemple : définir une limite supérieure

Vous pouvez utiliser min pour empêcher une valeur calculée de dépasser un certain montant.

Exemple : plafonner à 1 000 une remise de 20%

min(Prix × 20%, 1000)

Cette formule calcule une remise de 20% à partir du prix, mais si le montant de la remise dépasse 1 000, il est limité à 1 000.

Ainsi, min / max vous aide à créer facilement des calculs conditionnels simples.

10.14 Virgule : ,

La virgule sert à séparer plusieurs valeurs dans des fonctions comme min et max.

max(100, 200, 300)

Cette virgule n’est pas un séparateur de milliers. Elle sert à séparer les arguments d’une fonction.

11. Points à vérifier lors de l’utilisation des fonctions

Gardez les points suivants à l’esprit lorsque vous utilisez les fonctions.

11.1 Fermer les parenthèses

Les fonctions exigent que la valeur à calculer soit placée entre parenthèses.

Exemples corrects :

√(9)
sin(30)

Exemples incomplets :

√(
sin(30

Si les parenthèses ne sont pas fermées, l’expression ne peut pas être calculée.

11.2 min / max nécessitent au moins deux valeurs

min et max comparent plusieurs valeurs.

Exemple correct :

max(100, 200)

Exemple incomplet :

max(100)

Avec une seule valeur, il n’y a rien à comparer. Saisissez donc deux valeurs ou plus.

11.3 Placer les virgules correctement

Les virgules doivent être placées entre les valeurs.

Exemple correct :

max(100, 200, 300)

Exemples incomplets :

max(100, 200, )
max(,100)

11.4 Certaines valeurs ne peuvent pas être calculées

Certaines fonctions ne peuvent pas calculer certaines valeurs, par exemple √(-1), log(0) ou ln(0).

Dans ce cas, vérifiez l’expression saisie.

11.5 Vérifier l’unité d’angle pour les fonctions trigonométriques

Lorsque vous utilisez sin, cos ou tan, vérifiez que l’unité d’angle est réglée sur DEG ou RAD selon votre intention.

Par exemple, en DEG :

sin(30) = 0,5

En RAD, la même valeur 30 a une signification différente.

12. Résumé

CalcPad est une application de calculatrice qui vous permet d’utiliser une calculatrice classique tout en enregistrant et en réutilisant les formules et valeurs que vous utilisez souvent.

  • Enregistrez les calculs fréquents sous forme de formules
  • Enregistrez les valeurs fréquentes comme préréglages
  • Réutilisez les résultats et expressions avec COPY / PASTE
  • Retrouvez les valeurs déjà copiées depuis HISTORY
  • Utilisez les fonctions de base avec PRO pour des calculs plus flexibles

CalcPad réduit les saisies répétées et rend les calculs du quotidien plus fluides.
