1. CalcPad로 할 수 있는 일

CalcPad에서는 주로 다음 작업을 할 수 있습니다.

  • 일반 계산기처럼 계산하기
  • 자주 사용하는 계산식을 만들고 저장하기
  • 저장한 계산식을 불러와 변수만 입력해서 계산하기
  • 자주 사용하는 숫자를 프리셋으로 등록하기
  • 계산 결과나 식을 복사하기
  • 복사 기록에서 이전에 복사한 값을 다시 사용하기
  • 기본 함수를 사용해 계산하기

목차로 돌아가기

2. 일반 계산기로 사용하기

CalcPad의 메인 화면에서는 일반 계산기처럼 숫자와 연산자를 입력해 계산할 수 있습니다.

기본 조작

  1. 숫자를 입력합니다.
  2. +, −, ×, ÷ 등의 연산자를 입력합니다.
  3. = 를 탭하면 계산 결과가 표시됩니다.

계산 결과는 화면에 로그로 남기 때문에, 직전 계산 내용을 확인하면서 계속 계산할 수 있습니다.

목차로 돌아가기

3. 계산식 만들기

CalcPad의 핵심 기능은 자주 사용하는 계산식을 만들어 저장할 수 있다는 점입니다.

예를 들어 다음과 같은 계산식을 등록할 수 있습니다.

단가 × 수량
시급 × 작업 시간 + 기본급
매출 − 비용
체중 ÷ 키 ^ 2

저장한 계산식은 나중에 불러와 필요한 값만 입력해서 계산할 수 있습니다.

계산식 작성 흐름

  1. 기본 정보를 입력합니다
  2. 결과 표시 설정을 확인합니다
  3. 변수를 정의합니다
  4. 계산식을 만듭니다
  5. 저장합니다

3.1 기본 정보 입력하기

먼저 계산식의 이름을 입력합니다.

나중에 계산식 목록에서 봤을 때 알아보기 쉬운 이름으로 정해 두면 편리합니다.

3.2 결과 표시 설정 확인하기

계산 결과가 표시되는 방식을 설정할 수 있습니다.

  • 결과 이름: 계산 결과를 어떤 이름으로 표시할지 정합니다. 비워 두면 “결과”로 표시됩니다.
  • 소수 자릿수: 계산 결과에 표시할 소수점 이하 자릿수입니다.
  • 반올림 방식: 지정한 소수 자릿수로 맞출 때의 처리 방식입니다(반올림 / 내림 / 올림).

금액 계산에서는 소수점 이하를 표시하지 않고, 비율 계산에서는 소수점 이하를 표시하는 식으로 계산식마다 알맞게 조정할 수 있습니다.

3.3 변수 정의하기

변수란 계산할 때마다 입력하는 값을 말합니다.

예를 들어 다음 계산식에서는 단가와 수량이 변수입니다.

단가 × 수량 × 1.1

계산식을 실행할 때 단가와 수량의 값을 입력하면 CalcPad가 결과를 계산합니다.

변수 추가

변수를 추가할 때는 다음 정보를 입력합니다.

  • 타입: 숫자 / 퍼센트(%)
  • 변수 이름: 변수의 이름입니다(예: 단가, 수량 등).
  • 초기값: 변수에 미리 값을 넣어 두고 싶을 때 입력합니다. 이 값은 계산할 때마다 변경할 수 있습니다.
  • 키(a-z): 계산식을 만들 때 변수 이름 대신 사용하는 알파벳입니다.

3.4 계산식 만들기

변수를 사용해 실제 계산식을 만듭니다.

예:

a: 단가
b: 수량

a × b × 1.1

변수를 사용하면 매번 바뀌는 값만 입력하여 같은 계산을 반복할 수 있습니다.

3.5 함수가 포함된 계산식 만들기

PRO에서는 계산식 안에서도 기본 함수를 사용할 수 있습니다.

max(매출1, 매출2, 매출3)
|예정 금액 - 실제 금액|
round(단가 × 수량)

함수를 사용하면 최댓값, 최솟값, 차이, 반올림 처리 등을 포함한 계산식을 만들 수 있습니다.

삼각 함수를 사용하는 계산식에서는 각도 단위(DEG / RAD)를 설정할 수 있습니다. 이 각도 단위는 해당 계산식에만 적용됩니다.

목차로 돌아가기

4. 저장한 계산식 사용하기

저장한 계산식은 계산식 목록에서 불러와 사용할 수 있습니다.

사용 방법

  1. 계산기 키패드의 f(x) 버튼으로 계산식 목록을 엽니다.
  2. 사용할 계산식을 선택합니다.
  3. 표시된 변수에 값을 입력합니다.
  4. 필요한 값을 모두 입력하면 계산 결과가 표시됩니다.

예: 단가 × 수량 × 1.1

등록한 계산식:

단가 × 수량 × 1.1

실행할 때 입력하는 값:

[단가] = 1200
[수량] = 3

결과:

[결과] = 3960

같은 계산식을 여러 번 사용할 때도 매번 입력하는 것은 변수의 값뿐입니다.

목차로 돌아가기

5. 프리셋 사용하기

프리셋은 자주 사용하는 숫자를 등록해 둘 수 있는 기능입니다.

예를 들어 세율, 수수료, 자주 쓰는 단가, 고정비 등을 등록해 두면 입력 시간을 줄일 수 있습니다.

프리셋 예

라벨 값
소비세 10% 0.1
수수료 330
기본 요금 980
시급 1500

5.1 프리셋 사용하기

  1. 계산기 키패드의 PRE 버튼을 탭해 프리셋 시트를 엽니다.
  2. 입력할 프리셋을 탭합니다.

5.2 프리셋 추가 / 편집 / 삭제

  • 프리셋 시트 오른쪽 위의 + 버튼으로 추가할 수 있습니다.
  • 각 프리셋 오른쪽의 점 세 개 메뉴에서 편집 / 삭제를 할 수 있습니다.

목차로 돌아가기

6. COPY 사용하기

CalcPad에서는 계산 결과나 로그 내용을 복사할 수 있습니다.

6.1 직전 계산 결과 복사하기

COPY 버튼을 탭하면 직전 계산 결과를 복사할 수 있습니다.

예를 들어 다음과 같은 결과가 표시되어 있을 때:

1200 × 5 × 80%
= 4800

COPY 를 탭하면 4800 을 복사할 수 있습니다.

복사한 값은 나중에 PASTE 로 붙여넣거나 프리셋으로 등록할 수 있습니다.

6.2 로그 행을 선택해 복사하기

디스플레이의 로그 행(계산 기록 행)을 길게 누르면 해당 행을 선택할 수 있습니다.

선택한 상태에서 COPY 를 탭하면 그 행의 식이나 값을 복사할 수 있습니다.

예를 들어 다음과 같은 로그가 있을 때:

1200 × 5 × 80%
= 4800

식이 있는 행을 선택하면 식을 복사할 수 있고, 결과 행을 선택하면 결과를 복사할 수 있습니다.

목차로 돌아가기

7. PASTE 사용하기

PASTE 는 직전에 복사한 값이나 식을 입력란에 붙여넣는 기능입니다.

사용 방법

  1. COPY 로 값이나 식을 복사합니다.
  2. 붙여넣고 싶은 위치로 커서를 이동합니다.
  3. PASTE 를 탭합니다.

복사한 결과를 다른 계산에 이어서 사용하고 싶을 때 편리합니다.

목차로 돌아가기

8. HISTORY(복사 기록) 사용하기

PASTE 버튼을 길게 누르면 복사 기록 시트를 열 수 있습니다.

복사 기록에는 이전에 복사한 값이나 식이 저장됩니다.

HISTORY에서 할 수 있는 일

  • 기록에서 선택해 붙여넣기
  • 기록의 값을 프리셋으로 등록하기
  • 기록 내용을 OS 클립보드에 복사하기
  • 필요 없는 기록 삭제하기

9. 함수 사용하기(PRO 기능)

PRO에서는 기본 함수와 상수를 사용할 수 있습니다.

함수는 일반 계산기 화면과 계산식 작성 화면에서 사용할 수 있습니다.

함수 키패드 열기

일반 계산기 화면에서는 키패드 상단의 Func 버튼으로 함수 키패드를 열 수 있습니다.

함수 키패드에서는 제곱근, 절댓값, 삼각 함수, 로그, 반올림, 최댓값, 최솟값 등을 입력할 수 있습니다.

9.1 각도 단위

sin, cos, tan 등의 삼각 함수에서는 각도 단위를 사용합니다.

CalcPad에서는 다음 각도 단위를 선택할 수 있습니다.

표시 의미
DEG 도 단위
RAD 라디안

일반 계산기 화면에서 선택한 각도 단위는 일반 계산기용 설정으로 저장됩니다.

계산식 작성 화면에서는 각도 단위가 계산식마다 저장됩니다. 따라서 일반 계산기의 각도 단위를 변경해도 저장된 계산식의 결과는 바뀌지 않습니다.

9.2 입력 후 함수 패널 닫기

함수 키패드에는 입력 후 자동으로 닫는 설정이 있습니다.

OFF일 때는 함수를 입력해도 함수 키패드가 열린 상태로 유지됩니다. ON일 때는 함수를 입력한 뒤 함수 키패드가 닫힙니다.

여러 함수를 연속해서 입력하고 싶다면 OFF로 두고 사용하는 것이 편리합니다.

10. 함수 목록과 사용 예

이 섹션에서는 CalcPad에서 사용할 수 있는 주요 함수와 상수를 소개합니다.

10.1 제곱근: √

제곱근을 구하는 함수입니다.

√(9)

결과:

3

면적에서 정사각형 한 변의 길이를 구하는 계산 등에 사용할 수 있습니다.

10.2 절댓값: |x|

절댓값은 값을 항상 0 이상인 수로 다루기 위한 함수입니다.

|1200 - 1500|

결과:

300

차이나 오차를 양수로 보고 싶을 때 편리합니다.

사용 예: 예정 금액과 실제 금액의 차이 보기

|예정 금액 - 실제 금액|

예정보다 많거나 적은지와 관계없이 차이의 크기만 구할 수 있습니다.

10.3 원주율: π

원주율을 입력할 수 있습니다.

π

원의 계산 등에 사용할 수 있습니다.

사용 예: 반지름 5인 원의 넓이

π × 5 ^ 2

10.4 오일러 수: e

오일러 수를 입력할 수 있습니다.

e

지수 계산이나 자연로그 계산에서 사용합니다.

10.5 e의 x제곱: e^x

e 를 지정한 값만큼 거듭제곱합니다.

e^(2)

지수 함수를 사용하는 계산에 사용합니다.

10.6 삼각 함수: sin / cos / tan

각도와 관련된 계산을 하는 함수입니다.

sin(30)

각도 단위가 DEG일 때 결과는 다음과 같습니다.

0.5

삼각 함수를 사용할 때는 각도 단위가 DEG인지 RAD인지 확인하세요.

10.7 상용로그: log

log 는 밑이 10인 로그입니다.

log(100)

결과:

2

10.8 자연로그: ln

ln 은 밑이 e인 로그입니다.

ln(e)

결과:

1

10.9 반올림: round

소수를 반올림합니다.

round(12.6)

결과:

13
round(12.4)

결과:

12

금액이나 개수처럼 소수를 정수로 정리하고 싶을 때 사용할 수 있습니다.

10.10 내림: floor

소수를 내림합니다.

floor(12.9)

결과:

12

소수 부분을 항상 아래쪽으로 처리하고 싶을 때 사용합니다.

10.11 올림: ceil

소수를 올림합니다.

ceil(12.1)

결과:

13

필요 수량이나 박스 수처럼 조금이라도 초과하면 하나 더 필요한 계산에 편리합니다.

사용 예: 한 박스에 6개씩 들어가는 상품의 필요 박스 수

ceil(필요 수량 ÷ 6)

필요 수량이 13개일 때:

ceil(13 ÷ 6)

결과:

3

10.12 최솟값・최댓값: min / max

min 은 여러 값 중 가장 작은 값을, max 는 여러 값 중 가장 큰 값을 구합니다.

min(240 ÷ 2, 138, 15 × 10)

결과:

120
max(240 ÷ 2, 138, 15 × 10)

결과:

150

min 과 max 는 단순히 최솟값・최댓값을 구할 때뿐 아니라, 계산식 안에서 상한이나 하한을 두고 싶을 때도 유용합니다.

10.13 min / max 응용 예

min 과 max 를 사용하면 계산식 안에서 “일정 값을 넘지 않게 하기”, “일정 값보다 작아지지 않게 하기”, “일정 값을 넘은 부분만 계산하기” 같은 처리를 만들 수 있습니다.

응용 예: 일정 값을 넘은 부분만 더하기

max 를 사용하면 일정 값을 넘은 부분만 계산에 사용할 수 있습니다.

예: 배달 보상 계산

  • 기본 보상은 3600
  • 배달 거리 10km까지는 기본 보상만 적용
  • 10km를 넘은 부분은 1km당 100 추가
3600 + 100 × max(0, 거리 - 10)

max(0, 거리 - 10) 에 의해 거리가 10km 이하이면 추가분은 0이 되고, 10km를 넘은 경우에만 초과분이 더해집니다.

응용 예: 상한 설정하기

min 을 사용하면 계산 결과가 일정 값을 넘지 않도록 할 수 있습니다.

예: 20% 할인 금액에 상한 1000 설정하기

min(가격 × 20%, 1000)

가격의 20%를 할인 금액으로 계산하면서, 할인 금액이 1000을 넘는 경우에는 1000으로 제한됩니다.

이처럼 min / max 를 사용하면 간단한 조건이 들어간 계산식도 만들 수 있습니다.

10.14 쉼표: ,

쉼표는 min 이나 max 등에서 여러 값을 구분하기 위해 사용합니다.

max(100, 200, 300)

쉼표는 자릿수 구분 기호가 아니라 함수의 인수를 구분하기 위한 기호입니다.

11. 함수를 사용할 때의 주의점

함수를 사용할 때는 다음 사항에 주의하세요.

11.1 괄호 닫기

함수에서는 괄호 안에 계산할 값을 입력합니다.

올바른 예:

√(9)
sin(30)

불완전한 예:

√(
sin(30

괄호가 닫혀 있지 않으면 계산할 수 없습니다.

11.2 min / max에는 두 개 이상의 값이 필요

min 과 max 는 여러 값을 비교하기 위한 함수입니다.

올바른 예:

max(100, 200)

불완전한 예:

max(100)

값이 하나뿐이면 비교할 대상이 없으므로 두 개 이상의 값을 입력하세요.

11.3 쉼표 위치 주의하기

쉼표는 값과 값 사이에 입력합니다.

올바른 예:

max(100, 200, 300)

불완전한 예:

max(100, 200, )
max(,100)

11.4 계산할 수 없는 값이 있음

√(-1), log(0), ln(0) 처럼 함수에 따라 계산할 수 없는 값이 있습니다.

이런 경우에는 입력 내용을 확인하세요.

11.5 삼각 함수에서는 각도 단위 확인하기

sin, cos, tan 을 사용할 때는 각도 단위가 DEG인지 RAD인지 확인하세요.

예를 들어 DEG에서는 다음과 같이 계산됩니다.

sin(30) = 0.5

RAD에서는 같은 30 이라도 의미가 달라집니다.

12. 정리

CalcPad는 일반 계산기로 사용하면서 자주 쓰는 계산식과 값을 저장해 다시 사용할 수 있는 계산기 앱입니다.

  • 자주 쓰는 계산은 계산식으로 저장하기
  • 자주 쓰는 값은 프리셋으로 등록하기
  • 계산 결과와 식은 COPY / PASTE로 재사용하기
  • 이전에 복사한 값은 HISTORY에서 불러오기
  • PRO에서는 기본 함수를 사용해 더 유연하게 계산하기

매번 같은 계산을 입력하는 번거로움을 줄이고, 일상적인 계산을 더 부드럽게 처리할 수 있습니다.
