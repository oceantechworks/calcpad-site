1. Qué puedes hacer con CalcPad

CalcPad te permite hacer principalmente lo siguiente:

  • Usarla como una calculadora normal
  • Crear y guardar fórmulas que usas con frecuencia
  • Abrir fórmulas guardadas y calcular introduciendo solo las variables
  • Guardar números frecuentes como valores predefinidos
  • Copiar resultados de cálculo y expresiones
  • Reutilizar valores desde el historial de copia
  • Calcular con funciones básicas

2. Usar CalcPad como calculadora normal

En la pantalla principal, puedes introducir números y operadores igual que en una calculadora normal.

Uso básico

  1. Introduce un número.
  2. Introduce un operador como +, −, × o ÷.
  3. Toca = para mostrar el resultado.

Los cálculos quedan en la pantalla como un registro, por lo que puedes seguir calculando mientras revisas las entradas recientes.

3. Crear una fórmula

Una de las funciones principales de CalcPad es poder crear y guardar fórmulas que usas con frecuencia.

Por ejemplo, puedes guardar fórmulas como estas:

Precio unitario × Cantidad
Tarifa por hora × Horas trabajadas + Pago base
Ingresos − Gastos
Peso ÷ Altura ^ 2

Después de guardar una fórmula, puedes abrirla más tarde y calcular introduciendo solo los valores necesarios.

Flujo para crear una fórmula

  1. Introducir la información básica
  2. Revisar la configuración de visualización del resultado
  3. Definir las variables
  4. Crear la fórmula
  5. Guardarla

3.1 Introducir la información básica

Primero, introduce un nombre para la fórmula.

Elige un nombre que sea fácil de reconocer después en la lista de fórmulas.

3.2 Revisar la configuración de visualización del resultado

Puedes ajustar cómo se muestra el resultado del cálculo.

  • Nombre del resultado: el nombre que se usa al mostrar el resultado. Si lo dejas en blanco, se muestra como “Resultado”.
  • Decimales: el número de decimales que se mostrarán en el resultado.
  • Redondeo: cómo se redondea el resultado al número de decimales especificado (redondear / redondear hacia abajo / redondear hacia arriba).

Por ejemplo, puedes ocultar los decimales en cálculos de dinero o mostrarlos en cálculos de proporciones.

3.3 Definir las variables

Una variable es un valor que introduces cada vez que ejecutas una fórmula.

Por ejemplo, en la siguiente fórmula, Precio unitario y Cantidad son variables.

Precio unitario × Cantidad × 1.1

Cuando ejecutes la fórmula, introduce los valores de Precio unitario y Cantidad, y CalcPad calculará el resultado.

Agregar una variable

Al agregar una variable, introduce la siguiente información:

  • Tipo: número / porcentaje (%)
  • Nombre de variable: el nombre de la variable, como Precio unitario o Cantidad.
  • Valor inicial: introdúcelo si quieres que la variable tenga un valor predeterminado. Puedes cambiar este valor cada vez que calcules.
  • Clave (a-z): la letra que se usa en la fórmula en lugar del nombre de la variable.

3.4 Crear la fórmula

Crea la fórmula real usando variables.

Ejemplo:

a: Precio unitario
b: Cantidad

a × b × 1.1

Al usar variables, puedes repetir el mismo cálculo introduciendo solo los valores que cambian cada vez.

3.5 Crear una fórmula con funciones

Con PRO, también puedes usar funciones básicas dentro de las fórmulas.

max(Ventas 1, Ventas 2, Ventas 3)
|Importe previsto - Importe real|
round(Precio unitario × Cantidad)

Las funciones te permiten crear fórmulas que incluyen valores máximos, valores mínimos, diferencias, redondeos y más.

Al usar funciones trigonométricas, puedes configurar la unidad de ángulo (DEG / RAD). Esta unidad de ángulo se aplica solo a esa fórmula.

4. Usar una fórmula guardada

Las fórmulas guardadas se pueden seleccionar y usar desde la lista de fórmulas.

Cómo usar una fórmula

  1. Abre la lista de fórmulas con el botón f(x) del teclado de la calculadora.
  2. Selecciona la fórmula que quieres usar.
  3. Introduce valores para las variables mostradas.
  4. Cuando hayas introducido todos los valores necesarios, se mostrará el resultado.

Ejemplo: Precio unitario × Cantidad × 1.1

Fórmula guardada:

Precio unitario × Cantidad × 1.1

Valores introducidos al ejecutar la fórmula:

[Precio unitario] = 1200
[Cantidad] = 3

Resultado:

[Resultado] = 3960

Aunque uses la misma fórmula muchas veces, solo tienes que introducir los valores de las variables cada vez.

5. Usar valores predefinidos

Los valores predefinidos te permiten guardar números que usas con frecuencia.

Por ejemplo, guardar impuestos, comisiones, precios unitarios frecuentes o costos fijos puede reducir la entrada manual.

Ejemplos de valores predefinidos

Etiqueta Valor
Impuesto 10% 0.1
Comisión 330
Cargo base 980
Tarifa por hora 1500

5.1 Usar un valor predefinido

  1. Toca el botón PRE del teclado de la calculadora para abrir la hoja de valores predefinidos.
  2. Toca el valor predefinido que quieres introducir.

5.2 Agregar, editar o eliminar valores predefinidos

  • Puedes agregar un valor predefinido con el botón + en la parte superior derecha de la hoja de valores predefinidos.
  • Puedes editar o eliminar un valor predefinido desde el menú de tres puntos situado a la derecha de cada elemento.

Volver al índice

6. Usar COPY

CalcPad te permite copiar resultados de cálculo y entradas del registro.

6.1 Copiar el resultado de cálculo más reciente

Toca el botón COPY para copiar el resultado de cálculo más reciente.

Por ejemplo, si se muestra el siguiente resultado:

1200 × 5 × 80%
= 4800

Toca COPY para copiar 4800.

Más tarde puedes pegar el valor copiado con PASTE o registrarlo como valor predefinido.

6.2 Seleccionar y copiar una entrada del registro

Mantén presionada una entrada del registro en la pantalla para seleccionarla.

Con una entrada seleccionada, toca COPY para copiar esa expresión o valor.

Por ejemplo, si aparece este registro:

1200 × 5 × 80%
= 4800

Selecciona la línea de la expresión para copiar la expresión, o la línea del resultado para copiar el resultado.

7. Usar PASTE

PASTE inserta en el campo de entrada el valor o la expresión copiados más recientemente.

Cómo usar PASTE

  1. Copia un valor o una expresión con COPY.
  2. Mueve el cursor a la posición donde quieres pegarlo.
  3. Toca PASTE.

Esto es útil cuando quieres reutilizar un resultado copiado en otro cálculo.

Volver al índice

8. Usar HISTORY

Mantén presionado el botón PASTE para abrir la hoja del historial de copia.

El historial de copia guarda valores y expresiones que copiaste anteriormente.

Qué puedes hacer con HISTORY

  • Seleccionar un elemento del historial y pegarlo
  • Registrar un valor del historial como valor predefinido
  • Copiar un elemento del historial al portapapeles del sistema
  • Eliminar elementos innecesarios del historial

9. Usar funciones (función PRO)

Con PRO, puedes usar funciones y constantes básicas.

Las funciones se pueden usar en la pantalla de calculadora normal y en el editor de fórmulas.

Abrir el teclado de funciones

En la pantalla de calculadora normal, toca el botón Func en la parte superior del teclado para abrir el teclado de funciones.

El teclado de funciones te permite introducir raíces cuadradas, valores absolutos, funciones trigonométricas, logaritmos, funciones de redondeo, valores máximos, valores mínimos y más.

9.1 Unidades de ángulo

Las funciones trigonométricas como sin, cos y tan usan una unidad de ángulo.

CalcPad admite las siguientes unidades de ángulo:

Visualización Significado
DEG Grados
RAD Radianes

La unidad de ángulo seleccionada en la pantalla de calculadora normal se guarda como ajuste de la calculadora normal.

En el editor de fórmulas, la unidad de ángulo se guarda para cada fórmula. Por eso, cambiar la unidad de ángulo de la calculadora normal no cambia los resultados de las fórmulas guardadas.

9.2 Cerrar el panel de funciones después de introducir una función

El teclado de funciones tiene un ajuste para cerrarse automáticamente después de introducir una función.

Cuando este ajuste está desactivado, el teclado de funciones permanece abierto después de introducir una función. Cuando está activado, el teclado se cierra después de introducir una función.

Si quieres introducir varias funciones seguidas, es útil mantener este ajuste desactivado.

10. Lista de funciones y ejemplos

Esta sección presenta las principales funciones y constantes disponibles en CalcPad.

10.1 Raíz cuadrada: √

Calcula la raíz cuadrada de un valor.

√(9)

Resultado:

3

Es útil, por ejemplo, para calcular el lado de un cuadrado a partir de su área.

10.2 Valor absoluto: |x|

El valor absoluto trata un número como un valor siempre igual o mayor que cero.

|1200 - 1500|

Resultado:

300

Es útil cuando quieres ver una diferencia o un error como un valor positivo.

Ejemplo: ver la diferencia entre un importe previsto y uno real

|Importe previsto - Importe real|

Obtienes solo el tamaño de la diferencia, sin importar si el importe real es mayor o menor.

10.3 Pi: π

Introduce pi.

π

Es útil para cálculos relacionados con círculos.

Ejemplo: área de un círculo con radio 5

π × 5 ^ 2

10.4 Número de Euler: e

Introduce el número de Euler.

e

Se usa en cálculos exponenciales y logaritmos naturales.

10.5 e elevado a x: e^x

Eleva e a la potencia especificada.

e^(2)

Se usa en cálculos con funciones exponenciales.

10.6 Funciones trigonométricas: sin / cos / tan

Estas funciones se usan para cálculos relacionados con ángulos.

sin(30)

Cuando la unidad de ángulo es DEG, el resultado es:

0.5

Al usar funciones trigonométricas, asegúrate de que la unidad de ángulo esté configurada en DEG o RAD según lo que necesites.

10.7 Logaritmo común: log

log es el logaritmo en base 10.

log(100)

Resultado:

2

10.8 Logaritmo natural: ln

ln es el logaritmo en base e.

ln(e)

Resultado:

1

10.9 Redondear: round

Redondea un valor decimal al entero más cercano.

round(12.6)

Resultado:

13
round(12.4)

Resultado:

12

Es útil cuando quieres convertir decimales en números enteros para dinero, cantidades y cálculos similares.

10.10 Redondear hacia abajo: floor

Redondea un valor decimal hacia abajo.

floor(12.9)

Resultado:

12

Úsala cuando siempre quieras redondear la parte decimal hacia abajo.

10.11 Redondear hacia arriba: ceil

Redondea un valor decimal hacia arriba.

ceil(12.1)

Resultado:

13

Es útil para cálculos como cajas o lotes necesarios, donde cualquier resto significa que se necesita uno más.

Ejemplo: número de cajas necesarias cuando una caja contiene 6 unidades

ceil(Cantidad necesaria ÷ 6)

Si la cantidad necesaria es 13:

ceil(13 ÷ 6)

Resultado:

3

10.12 Mínimo y máximo: min / max

min devuelve el valor más pequeño entre varios valores, y max devuelve el valor más grande.

min(240 ÷ 2, 138, 15 × 10)

Resultado:

120
max(240 ÷ 2, 138, 15 × 10)

Resultado:

150

min y max no solo sirven para encontrar el valor más pequeño o más grande. También son útiles cuando quieres establecer un límite superior o inferior dentro de una fórmula.

10.13 Ejemplos con min / max

Con min y max, puedes crear fórmulas que impidan que un valor supere cierta cantidad, que baje de cierta cantidad, o que calculen solo la parte que supera un umbral.

Ejemplo: sumar solo la parte que supera un umbral

Puedes usar max para calcular solo la parte que supera cierto valor.

Ejemplo: cálculo de recompensa por entrega

  • La recompensa base es 3600
  • Hasta 10 km, solo se paga la recompensa base
  • Por la distancia que supera 10 km, se agregan 100 por km
3600 + 100 × max(0, Distancia - 10)

Con max(0, Distancia - 10), el importe adicional es 0 cuando la distancia es de 10 km o menos. Solo se suma la distancia que supera 10 km.

Ejemplo: establecer un límite superior

Puedes usar min para impedir que un valor calculado supere cierta cantidad.

Ejemplo: establecer un descuento máximo de 1000 para un descuento del 20%

min(Precio × 20%, 1000)

Esto calcula un descuento del 20% a partir del precio, pero si el descuento supera 1000, se limita a 1000.

De esta forma, min / max te ayudan a crear cálculos condicionales simples.

10.14 Coma: ,

La coma se usa para separar varios valores en funciones como min y max.

max(100, 200, 300)

Esta coma no es un separador de miles. Se usa para separar los argumentos de una función.

11. Notas al usar funciones

Ten en cuenta los siguientes puntos al usar funciones.

11.1 Cerrar los paréntesis

Las funciones requieren que el valor que se va a calcular esté dentro de paréntesis.

Ejemplos correctos:

√(9)
sin(30)

Ejemplos incompletos:

√(
sin(30

Si los paréntesis no están cerrados, la expresión no se puede calcular.

11.2 min / max requieren dos o más valores

min y max comparan varios valores.

Ejemplo correcto:

max(100, 200)

Ejemplo incompleto:

max(100)

Con un solo valor no hay nada con qué comparar. Introduce dos o más valores.

11.3 Colocar las comas correctamente

Las comas deben colocarse entre los valores.

Ejemplo correcto:

max(100, 200, 300)

Ejemplos incompletos:

max(100, 200, )
max(,100)

11.4 Algunos valores no se pueden calcular

Algunas funciones no pueden calcular ciertos valores, como √(-1), log(0) o ln(0).

Si esto ocurre, revisa la expresión que introdujiste.

11.5 Revisar la unidad de ángulo en funciones trigonométricas

Al usar sin, cos o tan, asegúrate de que la unidad de ángulo esté configurada en DEG o RAD según lo que necesites.

Por ejemplo, en DEG:

sin(30) = 0.5

En RAD, el mismo valor 30 tiene un significado diferente.

12. Resumen

CalcPad es una app de calculadora que te permite usar una calculadora normal mientras guardas y reutilizas fórmulas y valores frecuentes.

  • Guarda cálculos frecuentes como fórmulas
  • Registra valores frecuentes como valores predefinidos
  • Reutiliza resultados y expresiones con COPY / PASTE
  • Abre valores copiados anteriormente desde HISTORY
  • Usa funciones básicas con PRO para cálculos más flexibles

CalcPad ayuda a reducir entradas repetidas y hace que los cálculos cotidianos sean más fluidos.
