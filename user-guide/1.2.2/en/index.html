1. What you can do with CalcPad

CalcPad can be used for the following:

  • Use it as a regular calculator
  • Create and save frequently used formulas
  • Call up saved formulas and calculate by entering only the variables
  • Save frequently used numbers as presets
  • Copy calculation results and expressions
  • Reuse values from your copy history
  • Calculate with basic functions

Back to contents

2. Use CalcPad as a regular calculator

On the main screen, you can enter numbers and operators just like a regular calculator.

Basic operation

  1. Enter a number.
  2. Enter an operator such as +, −, ×, or ÷.
  3. Tap = to show the result.

Your calculations remain on the display as a log, so you can continue calculating while checking recent entries.

3. Create a formula

One of CalcPad’s main features is the ability to create and save frequently used formulas.

For example, you can save formulas like these:

Unit price × Quantity
Hourly rate × Hours worked + Base pay
Revenue − Expenses
Weight ÷ Height ^ 2

After saving a formula, you can call it up later and calculate by entering only the required values.

Formula creation flow

  1. Enter basic information
  2. Check the result display settings
  3. Define variables
  4. Create the formula
  5. Save it

3.1 Enter basic information

First, enter a name for the formula.

Choose a name that will be easy to recognize later in the formula list.

3.2 Check the result display settings

You can adjust how the calculation result is displayed.

  • Result name: The name used when displaying the calculation result. If left blank, it is shown as “Result”.
  • Decimal places: The number of decimal places to display in the result.
  • Rounding: How the result is rounded to the specified number of decimal places (Round / Round down / Round up).

For example, you can hide decimal places for money calculations or show decimal places for ratio calculations.

3.3 Define variables

A variable is a value you enter each time you run a formula.

For example, in the following formula, Unit price and Quantity are variables.

Unit price × Quantity × 1.1

When you run the formula, enter values for Unit price and Quantity, and CalcPad will calculate the result.

Add a variable

When adding a variable, enter the following information:

  • Type: Number / Percentage (%)
  • Variable name: The name of the variable, such as Unit price or Quantity.
  • Initial value: Enter this if you want the variable to have a default value. You can change this value each time you calculate.
  • Key (a-z): The alphabet key used in the formula instead of the variable name.

3.4 Create the formula

Create the actual formula using variables.

Example:

a: Unit price
b: Quantity

a × b × 1.1

By using variables, you can repeat the same calculation by entering only the values that change each time.

3.5 Create a formula with functions

With PRO, you can also use basic functions in formulas.

max(Sales 1, Sales 2, Sales 3)
|Planned amount - Actual amount|
round(Unit price × Quantity)

Functions let you create formulas that include maximum values, minimum values, differences, rounding, and more.

When using trigonometric functions, you can set the angle unit (DEG / RAD). This angle unit applies only to that formula.

4. Use a saved formula

Saved formulas can be selected and used from the formula list.

How to use a formula

  1. Open the formula list with the f(x) button on the calculator keypad.
  2. Select the formula you want to use.
  3. Enter values for the displayed variables.
  4. After all required values are entered, the calculation result is shown.

Example: Unit price × Quantity × 1.1

Saved formula:

Unit price × Quantity × 1.1

Values entered when running the formula:

[Unit price] = 1200
[Quantity] = 3

Result:

[Result] = 3960

Even when you use the same formula repeatedly, you only need to enter the variable values each time.

5. Use presets

Presets let you save numbers that you use often.

For example, saving tax rates, fees, common unit prices, or fixed costs can reduce manual input.

Preset examples

Label Value
Sales tax 10% 0.1
Fee 330
Base charge 980
Hourly rate 1500

5.1 Use a preset

  1. Tap the PRE button on the calculator keypad to open the preset sheet.
  2. Tap the preset you want to enter.

5.2 Add, edit, or delete presets

  • You can add a preset with the + button at the top right of the preset sheet.
  • You can edit or delete a preset from the three-dot menu on the right side of each preset.

6. Use COPY

CalcPad lets you copy calculation results and log entries.

6.1 Copy the latest calculation result

Tap the COPY button to copy the latest calculation result.

For example, if the following result is displayed:

1200 × 5 × 80%
= 4800

Tap COPY to copy 4800.

You can later paste the copied value with PASTE or register it as a preset.

6.2 Select and copy a log entry

Long-press a log entry on the display to select it.

With a log entry selected, tap COPY to copy that expression or value.

For example, if this log is shown:

1200 × 5 × 80%
= 4800

Select the expression line to copy the expression, or select the result line to copy the result.

7. Use PASTE

PASTE inserts the most recently copied value or expression into the input field.

How to use PASTE

  1. Copy a value or expression with COPY.
  2. Move the cursor to where you want to paste it.
  3. Tap PASTE.

This is useful when you want to reuse a copied result in another calculation.

Back to contents

8. Use HISTORY

Long-press the PASTE button to open the copy history sheet.

Your copy history stores values and expressions you copied before.

What you can do with HISTORY

  • Select an item from the history and paste it
  • Register a history value as a preset
  • Copy a history item to the OS clipboard
  • Delete unnecessary history items

9. Use functions (PRO feature)

With PRO, you can use basic functions and constants.

Functions can be used on the regular calculator screen and in the formula editor.

Open the function keypad

On the regular calculator screen, tap the Func button at the top of the keypad to open the function keypad.

The function keypad lets you enter square roots, absolute values, trigonometric functions, logarithms, rounding functions, maximum values, minimum values, and more.

9.1 Angle units

Trigonometric functions such as sin, cos, and tan use an angle unit.

CalcPad supports the following angle units:

Display Meaning
DEG Degrees
RAD Radians

The angle unit selected on the regular calculator screen is saved as the setting for the regular calculator.

In the formula editor, the angle unit is saved for each formula. Therefore, changing the regular calculator’s angle unit will not change the results of saved formulas.

9.2 Close the function panel after input

The function keypad has a setting to close automatically after input.

When this setting is OFF, the function keypad stays open after you enter a function. When it is ON, the function keypad closes after you enter a function.

If you want to enter multiple functions in a row, keeping this setting OFF is useful.

10. Function list and examples

This section introduces the main functions and constants available in CalcPad.

10.1 Square root: √

Calculates the square root of a value.

√(9)

Result:

3

This is useful for calculations such as finding the side length of a square from its area.

10.2 Absolute value: |x|

Absolute value treats a number as a value that is always zero or greater.

|1200 - 1500|

Result:

300

This is useful when you want to see a difference or error as a positive value.

Example: Find the difference between planned and actual amounts

|Planned amount - Actual amount|

This gives you only the size of the difference, regardless of whether the actual amount is higher or lower.

10.3 Pi: π

Enters pi.

π

This is useful for circle calculations.

Example: Area of a circle with radius 5

π × 5 ^ 2

10.4 Euler’s number: e

Enters Euler’s number.

e

This is used for exponential calculations and natural logarithms.

10.5 e to the power of x: e^x

Raises e to the specified power.

e^(2)

This is used for calculations involving exponential functions.

10.6 Trigonometric functions: sin / cos / tan

These functions are used for angle-related calculations.

sin(30)

When the angle unit is DEG, the result is:

0.5

When using trigonometric functions, make sure the angle unit is set to DEG or RAD as intended.

10.7 Common logarithm: log

log is the base-10 logarithm.

log(100)

Result:

2

10.8 Natural logarithm: ln

ln is the base-e logarithm.

ln(e)

Result:

1

10.9 Round: round

Rounds a decimal value to the nearest integer.

round(12.6)

Result:

13
round(12.4)

Result:

12

This is useful when you want to convert decimals into whole numbers for money, counts, and similar calculations.

10.10 Round down: floor

Rounds a decimal value down.

floor(12.9)

Result:

12

Use this when you always want to round the decimal part downward.

10.11 Round up: ceil

Rounds a decimal value up.

ceil(12.1)

Result:

13

This is useful for calculations such as required boxes or batches, where any remainder means one more is needed.

Example: Number of boxes needed when one box holds 6 items

ceil(Required quantity ÷ 6)

If the required quantity is 13:

ceil(13 ÷ 6)

Result:

3

10.12 Minimum and maximum: min / max

min returns the smallest value among multiple values, and max returns the largest value among multiple values.

min(240 ÷ 2, 138, 15 × 10)

Result:

120
max(240 ÷ 2, 138, 15 × 10)

Result:

150

min and max are not only useful for finding the smallest or largest value. They are also useful when you want to set an upper or lower limit inside a formula.

10.13 min / max examples

With min and max, you can create formulas that keep a value from going above a certain amount, keep a value from going below a certain amount, or calculate only the amount above a threshold.

Example: Add only the amount above a threshold

You can use max to calculate only the amount above a certain value.

Example: Delivery reward calculation

  • Base reward is 3600
  • Up to 10 km, only the base reward is paid
  • For the distance above 10 km, add 100 per km
3600 + 100 × max(0, Distance - 10)

With max(0, Distance - 10), the extra amount is 0 when the distance is 10 km or less. Only the distance above 10 km is added.

Example: Set an upper limit

You can use min to keep a calculated value from going above a certain amount.

Example: Set a maximum discount of 1000 for a 20% discount

min(Price × 20%, 1000)

This calculates a 20% discount from the price, but if the discount amount would exceed 1000, it is limited to 1000.

In this way, min / max can help you create simple conditional calculations.

10.14 Comma: ,

A comma is used to separate multiple values in functions such as min and max.

max(100, 200, 300)

The comma is not a thousands separator. It is used to separate function arguments.

11. Notes when using functions

Keep the following points in mind when using functions.

11.1 Close parentheses

Functions require the value to be calculated inside parentheses.

Correct examples:

√(9)
sin(30)

Incomplete examples:

√(
sin(30

If the parentheses are not closed, the expression cannot be calculated.

11.2 min / max require two or more values

min and max compare multiple values.

Correct example:

max(100, 200)

Incomplete example:

max(100)

Because there is nothing to compare with a single value, enter two or more values.

11.3 Place commas correctly

Commas should be placed between values.

Correct example:

max(100, 200, 300)

Incomplete examples:

max(100, 200, )
max(,100)

11.4 Some values cannot be calculated

Some functions cannot calculate certain values, such as √(-1), log(0), or ln(0).

If this happens, check the expression you entered.

11.5 Check the angle unit for trigonometric functions

When using sin, cos, or tan, make sure the angle unit is set to DEG or RAD as intended.

For example, in DEG:

sin(30) = 0.5

In RAD, the same value 30 has a different meaning.

12. Summary

CalcPad is a calculator app that lets you use a regular calculator while saving and reusing frequently used formulas and values.

  • Save frequently used calculations as formulas
  • Register frequently used values as presets
  • Reuse results and expressions with COPY / PASTE
  • Recall previously copied values from HISTORY
  • Use basic functions with PRO for more flexible calculations

CalcPad helps reduce repeated input and makes everyday calculations smoother.
