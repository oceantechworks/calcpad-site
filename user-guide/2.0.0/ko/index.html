1. CalcPad로 할 수 있는 일

CalcPad는 일반 계산 기능에 더해, 자주 쓰는 값과 수식을 저장해 반복해서 사용할 수 있는 계산기 앱입니다. 이 가이드에서는 저장한 수식을 ‘수식(템플릿)’이라고도 부릅니다.

  • 사칙연산, 괄호, 퍼센트, 거듭제곱으로 계산하기
  • ANS로 직전 결과를, HISTORY에서 이전 결과를 불러오기
  • 메모리에 값을 더하거나 빼서 합계 구하기
  • 자주 쓰는 숫자는 프리셋으로, 반복하는 계산 절차는 수식으로 저장하기
  • 함수와 상수 사용하기. 일부 함수와 백업 및 복원 기능은 PRO가 필요합니다

먼저 일반 계산을 해 본 다음, ANS나 HISTORY에서 결과를 재사용해 보세요.

처음 실행할 때 샘플 가져오기

첫 실행 시 “샘플 데이터를 불러오시겠습니까?”가 표시되면 “가져오기”를 선택해 수식 2개와 프리셋 3개를 가져올 수 있습니다. “가져오지 않기”를 선택해 빈 상태로 시작할 수도 있습니다. 두 방법 모두 Free에서 이용할 수 있습니다.

현재 샘플에는 BMI 등의 수식과 cm / 인치, 표준 중력 가속도 g, 황금비 φ 프리셋이 포함됩니다. 샘플도 편집하거나 삭제할 수 있습니다.

2. 일반 계산기로 사용하기

2.1 입력하고 계산하기

  1. 숫자와 연산자를 누르세요. 예: 1200 × 5 × 80%.
  2. =(아래쪽 표시는 ENTER)를 누르세요.
  3. 계산식과 결과 4800이 화면의 Log에 표시됩니다.

80%는 0.8을 의미합니다. 200 + 10%의 결과는 200.1입니다. 200에 10%를 더하려면 200 × (1 + 10%)로 입력하세요.

2.2 입력 수정하기

  • 입력 줄을 눌러 커서를 이동하세요. ◀/▶로도 좌우로 이동할 수 있습니다.
  • ⌫는 커서 바로 앞의 내용을 삭제합니다.
  • C/AC를 짧게 누르면 입력 중인 식을 지웁니다. 일반 계산기에서 길게 누르면 입력과 화면의 Log를 함께 지웁니다.
  • C/AC로는 ANS, HISTORY, 메모리가 지워지지 않습니다.

2.3 괄호, 거듭제곱, 이어서 계산하기

(2 + 3) × 4 = 20, 2 ^ 3 = 8과 같이 입력할 수 있습니다. 곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 계산됩니다. 결과를 사용해 다른 계산을 하려면 ANS를 이용하면 값을 다시 입력하지 않아도 됩니다.

2.4 Log 재사용하기

Log는 현재 화면에서 계산 과정을 확인하는 표시 영역입니다. 계산이 끝난 계산식 줄을 길게 누르면 현재 입력 줄의 커서 위치에 그 식을 삽입할 수 있습니다. 예를 들어 100×1.1+500을 불러온 뒤 100을 200으로 바꾸어 다시 계산할 수 있습니다.

계산 결과 줄을 길게 누르면 결과가 괄호로 묶인 확정값으로 삽입됩니다. 화면 표시의 자릿수를 줄였더라도 내부 계산값을 유지한 채 재사용할 수 있습니다. 수식(템플릿)의 확정된 변수 줄도 길게 눌러 재사용할 수 있으며, 변수 이름과 단위를 제외한 숫자만 확정값으로 삽입됩니다.

이 기능은 OS 클립보드에 복사하는 것이 아니라 CalcPad의 입력 줄에 삽입하는 기능입니다. 길게 누르는 것만으로 계산이 실행되지는 않습니다. 삽입 후 필요한 내용을 입력하거나 편집하고 =로 계산하세요. Log를 지워도 HISTORY의 기록은 남습니다.

목차로 돌아가기

3. ANS 사용하기

ANS에는 마지막으로 성공한 계산 결과 1개가 저장됩니다. 일반 계산과 수식을 끝까지 실행한 최종 결과가 대상입니다. 계산이 실패하거나 수식의 변수를 입력하는 도중에는 이전 ANS가 유지됩니다.

3.1 직전 결과 불러오기

  1. 12 × 8을 입력하고 =를 눌러 96을 구하세요.
  2. ANS를 짧게 누르세요. 커서 위치에 괄호로 묶인 녹색 값이 삽입됩니다.
  3. 이어서 ÷ 3을 입력하고 =를 누르면 32가 됩니다.

불러오기는 그 시점의 값을 삽입하는 동작입니다. 나중에 ANS가 바뀌어도 이미 삽입한 값은 바뀌지 않습니다. 화면에서 생략되거나 끝수 처리되어 보이는 자릿수만 옮기는 것이 아니라 보관된 계산값을 재사용합니다.

3.2 보관, 갱신, 지우기

  • ANS가 아직 설정되지 않았다면 짧게 눌러도 값이 삽입되지 않습니다. 0도 유효한 계산 결과입니다.
  • 정상적으로 저장되었다면 앱을 다시 열어도 유지됩니다.
  • 새로운 계산이 성공하면 ANS가 갱신됩니다. ANS만 지우는 전용 버튼은 없습니다.
  • HISTORY 삭제나 MC로는 ANS가 지워지지 않습니다. 백업에는 포함되지 않습니다.

ANS를 길게 누르면 HISTORY가 열립니다. 값을 삽입하는 짧게 누르기와는 다른 동작입니다.

목차로 돌아가기

4. HISTORY 사용하기

HISTORY는 성공한 계산의 식과 결과를 자동으로 기록하는 목록입니다. 최대 30개를 보관하며 한도를 넘으면 오래된 항목부터 제외합니다. 일반 계산과 수식의 최종 결과를 기록하며, 변수 입력의 중간 결과나 값을 삽입하기만 한 동작은 기록하지 않습니다.

계산식은 계산했을 때의 표시 그대로 확인할 수 있습니다. 나중에 소수 자릿수, 끝수 처리, 소수점 기호, 자리 구분 기호, 앱 언어를 바꿔도 기록한 식은 바뀌지 않습니다. 수식(템플릿)은 실행 당시의 변수값을 대입한 식과 당시 수식 이름을 표시합니다.

예를 들어 소수 6자리와 반올림 설정으로 1÷3을 계산하면 결과는 0.333333으로 표시됩니다. 이어서 ANS를 삽입해 (0.333333)×3을 계산하면 결과는 1입니다. HISTORY의 식도 1÷3과 (0.333333)×3으로 유지되며, 긴 내부 숫자로 바뀌거나 일반적인 표시상의 끝수 처리만으로 ≒가 붙지 않습니다. 0이 아닌 값이 화면에서 0으로 표시되는 경우의 ≒ 0 표시는 유지됩니다.

결과 표시는 계산 당시의 소수 자릿수와 끝수 처리 방식을 유지하며, 소수점과 자리 구분 표기만 현재 표시 설정을 따릅니다. 식이나 결과의 표시 자릿수를 줄였더라도 내부 계산 결과를 그 표시 자릿수에 맞춰 끝수 처리해 저장하는 것은 아닙니다. 보관된 고정밀 값을 그대로 재사용할 수 있습니다.

4.1 이전 결과 불러오기

  1. 홈의 ANS를 길게 누르세요. 키 아래쪽의 HISTORY 표시를 확인하세요.
  2. 최신 기록은 목록 아래에 있습니다. 위로 스크롤하면 오래된 기록을 확인할 수 있습니다.
  3. 사용할 항목의 계산식 영역이나 결과 영역을 누르세요.
  4. 삽입이 성공하면 계산기로 돌아가고 커서 위치에 괄호로 묶인 확정값이 들어갑니다.

삽입되는 것은 저장된 결과입니다. 기록의 식을 다시 계산하거나 편집용 식으로 불러오는 동작이 아닙니다. 삽입만으로 ANS, HISTORY, Log, 메모리가 갱신되지는 않습니다.

4.2 각 항목의 동작

조작동작
M+/M-해당 항목의 결과를 메모리에 더하거나 뺍니다. 홈의 M+/M-와는 사용하는 값이 다릅니다.
점 3개 메뉴 → 프리셋에 등록결과값을 유지한 채 이름을 붙여 저장합니다. 수식 기록에서는 수식 이름이 초기 이름이 됩니다.
점 3개 메뉴 → OS에 복사결과의 숫자를 기기의 클립보드에 복사해 다른 앱에 붙여 넣을 수 있습니다. 식 전체를 복사하는 기능은 아닙니다.
점 3개 메뉴 → 삭제해당 기록을 삭제합니다.

4.3 전체 삭제와 보관

화면 위쪽의 전체 삭제 버튼을 누르고 “모든 기록을 삭제할까요?”를 확인한 뒤 “지우기”를 선택하세요. 삭제한 기록은 되돌릴 수 없습니다. 개별 삭제와 전체 삭제 모두 ANS와 메모리는 변경하지 않습니다.

HISTORY는 정상적으로 저장되면 다음 실행 때도 사용할 수 있습니다. 백업에는 포함되지 않습니다. 저장 실패 시 주의 사항은 데이터 저장 및 불러오기 문제를 확인하세요.

목차로 돌아가기

5. 메모리 사용하기

메모리는 여러 결과를 더하거나 빼며 합계를 관리하는 저장 공간입니다. 초기값은 0이며 홈 위쪽과 HISTORY 맨 아래에 M = …로 표시됩니다.

키홈에서의 동작
MC메모리를 정확한 0으로 되돌립니다.
MR현재 메모리 값을 커서 위치에 삽입합니다. 메모리는 지우지 않습니다.
M+마지막으로 성공한 계산 결과(ANS)를 더합니다.
M-마지막으로 성공한 계산 결과(ANS)를 뺍니다.

5.1 100과 30을 더하는 예

  1. MC로 메모리를 0으로 만드세요.
  2. 100을 입력하고 =, M+ 순서로 누르세요. 메모리가 100이 됩니다.
  3. 30을 입력하고 =, M+ 순서로 누르세요. 메모리가 130이 됩니다.
  4. MR로 130을 입력 줄에 불러올 수 있습니다. ANS가 여전히 30일 때 M-를 누르면 메모리는 100이 됩니다.
M+/M-의 대상에 주의하세요

홈에서는 입력 중인 숫자가 아니라 ANS를 사용합니다. 100을 입력하기만 하고 M+를 눌러도 100이 더해지는 것은 아닙니다. 먼저 =로 정상적으로 계산을 완료하세요. ANS가 설정되지 않았다면 메모리는 바뀌지 않습니다. 수식의 변수 입력 중에도 직전의 최종 성공 결과를 사용합니다.

5.2 HISTORY에서 조작하기

각 기록 항목의 M+/M-는 해당 항목의 결과를 사용합니다. 맨 아래 M = … 표시에서 MC 왼쪽을 누르면 MR과 같이 값을 삽입하고 계산기로 돌아갑니다. MC는 메모리만 0으로 만들고 HISTORY 화면을 유지합니다.

메모리의 덧셈·뺄셈과 MC는 입력 중인 식, ANS, 기록을 변경하지 않습니다. MR은 입력 줄에 값을 삽입하기만 하며, MR 삽입만으로 새 성공 기록을 만들지 않습니다. 메모리는 정상적으로 저장되면 재시작 후에도 유지되지만 백업 대상이 아닙니다. 사용할 수 없을 때의 M = —는 정상적인 0과 다릅니다.

목차로 돌아가기

6. 프리셋 사용하기

프리셋은 단가, 세율, 환산 계수처럼 자주 쓰는 숫자를 이름과 함께 저장하는 기능입니다. 메모리처럼 더하거나 빼는 용도보다는 같은 값을 반복해서 불러오는 데 적합합니다.

6.1 등록하기

  1. PRE로 “프리셋”을 여세요.
  2. 오른쪽 위의 ＋로 추가하세요.
  3. 값과 필요한 경우 라벨을 입력하고 저장하세요. 예: 라벨 “시급”, 값 1500.

계산 결과를 그대로 보관하려면 HISTORY의 점 3개 메뉴에서 “프리셋에 등록”을 선택하세요. 화면에 표시된 자릿수로 다시 입력할 필요가 없습니다. 이 등록에서는 값은 고정되고 이름을 바꿀 수 있습니다.

6.2 불러오기와 편집

  • PRE를 열고 항목을 누르면 커서 위치에 괄호로 묶인 녹색 확정값이 삽입됩니다.
  • 각 항목의 점 3개 메뉴에서 “편집”, “삭제”를 선택하세요.
  • “순서 변경”을 선택한 뒤 항목을 드래그해 순서를 바꾸고, “완료”를 눌러 일반 표시로 돌아가세요.

Free는 최대 5개입니다. 첫 실행 시 가져온 샘플 3개도 개수에 포함됩니다. 현재 샘플에는 “cm / 인치: 2.54”, “표준 중력 가속도 g: 9.80665”, “황금비 φ: 1.618”이 있습니다. 원주율 π는 프리셋이 아니라 FUNC에서 입력할 수 있습니다.

프리셋은 백업 대상입니다. 샘플이 업데이트되어도 사용자가 이미 저장한 프리셋이 자동으로 새 내용으로 바뀌지는 않습니다.

목차로 돌아가기

7. 수식 만들기

매번 같은 절차로 계산한다면 수식을 저장해 달라지는 값만 입력하도록 만들 수 있습니다. 예를 들어 “단가 × 수량 × 1.1”을 만들어 보겠습니다.

  1. ƒ(x)로 “수식”을 열고 오른쪽 위의 ＋를 누르세요.
  2. “기본 정보”의 “수식 이름(필수)”에 “세금 포함 합계” 등의 이름을 입력하세요. 설명은 선택 사항입니다.
  3. “계산 결과 설정”에서 결과 이름, 소수 자릿수, 끝수 처리를 선택하세요.
  4. “변수”의 추가 버튼으로 숫자 타입의 “단가”(키 a)와 “수량”(키 b)을 등록하세요.
  5. “수식” 입력 영역에서 변수 버튼, 연산자, 숫자를 사용해 a × b × 1.1을 만드세요.
  6. “저장”을 누르세요.

7.1 변수란?

변수는 실행할 때마다 값을 입력하는 항목입니다. 예를 들어 이름은 “단가”, 식 안에서 사용하는 키는 a와 같이 지정합니다. 초기값을 설정하면 입력 후보로 사용할 수 있습니다. 수식을 저장하려면 변수를 1개 이상 등록하고, 식에서 등록된 변수를 1개 이상 사용해야 합니다. 등록한 변수를 모두 사용할 필요는 없습니다.

타입은 “숫자”와 “%”(퍼센트) 중에서 선택합니다. 퍼센트 변수 버튼은 식에 a%와 같이 들어가며, 실행 시 10을 입력하면 10%로 처리됩니다. 여기에 다시 100으로 나누는 식을 덧붙이지 않도록 주의하세요.

소문자 e는 네이피어 수로 예약되어 있어 변수 키로 사용할 수 없습니다.

7.2 함수, 끝수 처리, 편집

수식 작성 화면의 함수 버튼은 “Func”입니다. E, π, e는 Free에서도 사용할 수 있고 다른 함수는 PRO에서 이용할 수 있습니다. 삼각함수의 각도 단위는 수식별로 저장합니다.

수식의 소수 자릿수는 결과를 확정하는 설정입니다

여기서 지정한 소수 자릿수와 끝수 처리는 수식의 최종 결과 자체에 적용됩니다. 홈의 표시 자릿수만 바꾸는 설정과 다릅니다. ANS와 HISTORY에도 이 확정된 결과가 기록됩니다.

수식 목록의 점 3개 메뉴에서 편집하거나 삭제할 수 있습니다. “순서 변경”으로 순서도 바꿀 수 있습니다. 식에서 사용 중인 변수를 지우려면 먼저 식에서 그 변수를 제거하세요. 삭제는 되돌릴 수 없습니다.

목차로 돌아가기

8. 저장한 수식 실행하기

  1. ƒ(x)로 수식 목록을 열고 사용할 수식을 누르세요.
  2. 표시된 변수의 값을 입력하고 =/ENTER로 확정하세요.
  3. 다음 변수가 표시되면 같은 방법으로 입력하고 확정하세요.
  4. 마지막 변수를 확정하면 결과가 표시됩니다.

“단가 × 수량 × 1.1”에 단가 1200, 수량 3을 입력하면 결과는 3960입니다.

[단가] = 1200
[수량] = 3
[결과] = 3960

변수 입력란에서도 1200 × 2와 같은 계산이나 ANS, MR, 프리셋, HISTORY의 값 삽입을 사용할 수 있습니다. 결과를 표시한 뒤처럼 입력을 받지 않는 상태에서는 삽입할 수 없습니다.

성공한 최종 결과는 ANS를 갱신하고 수식 이름과 함께 HISTORY에 기록됩니다. 변수 입력 도중의 값만으로는 ANS가 갱신되지 않습니다. 입력을 중단하고 일반 계산기로 돌아가려면 C/AC를 길게 누르세요.

홈의 FUNC로 함수 키패드를 여세요. 다음과 같은 4열 × 4행 배치입니다. E, π, e는 Free에서, 나머지 13개 키는 PRO에서 사용할 수 있습니다.

함수 버튼으로 괄호 등이 삽입되면 커서 위치에 값을 입력하세요. “함수 설명”에서 앱 내 설명도 열 수 있습니다.

9.1 지수 표기 E와 상수 π, e

  • 1.2E3은 1.2 × 10^3 = 1200을 의미하고, 1.2E-3은 0.0012입니다. 숫자 뒤에 E를 입력하고 지수를 이어서 입력하세요. E만 있거나 지수가 입력되지 않은 상태에서는 계산할 수 없습니다.
  • π는 원주율입니다. 반지름이 5인 원의 넓이는 π × 5 ^ 2로 구하며 약 78.539816입니다(소수 6자리 표시 예).
  • 소문자 e는 네이피어 수로 약 2.718282입니다. 대문자 E를 사용하는 지수 표기와는 다릅니다.

9.3 min/max와 쉼표

min/max에는 값이 2개 이상 필요합니다. 일반 계산기에서 커서가 해당 인수 안에 있으면 계산 화면 오른쪽 아래에 , NEXT ARG가 표시됩니다. 입력 가능한 위치에서 누르면 쉼표와 공백 1개가 들어갑니다. 수식 작성 화면에서는 수식 빌더의 쉼표 버튼을 사용하세요.

여기서 쉼표는 인수 구분자입니다. 자리 구분 기호와 혼동하지 말고 max(100, 200)과 같이 입력하세요. 마지막 값이 없는 max(100, )는 완성된 식이 아닙니다.

9.4 활용 예제

필요한 물건이 13개이고 한 상자에 6개가 들어 있다면 필요한 상자 수는 ceil(13 ÷ 6) = 3개입니다.

기본 보수가 3600이고 거리 10km를 초과한 부분에만 1km당 100을 더하려면 3600 + 100 × max(0, a - 10)을 사용하세요(a는 거리). a가 8이면 3600, 15이면 4100입니다.

가격의 20%를 할인하되 할인액을 최대 1000으로 제한하려면 min(a × 20%, 1000)을 사용하세요(a는 가격). 3000이면 600, 8000이면 1000입니다.

9.5 각도 단위와 입력 후 동작

일반 계산기의 함수 시트에서 DEG(도)/RAD(라디안)를 선택하세요. 삼각함수가 포함된 식을 다룰 때 홈 위쪽에 DEG/RAD가 표시됩니다. 수식은 각각 저장된 각도 단위를 사용하며 일반 계산기 설정과는 독립적입니다.

일반 계산기의 “입력 후 자동으로 닫기”는 Free와 PRO에서 모두 사용할 수 있습니다. ON이면 입력 성공 시 함수 시트가 닫히고 OFF이면 열린 채로 유지됩니다. 수식 빌더의 함수 시트는 입력 성공 시 닫힙니다.

목차로 돌아가기

10. 계산 정밀도와 표시 설정

10.1 계산값과 화면 표시값은 다릅니다

CalcPad는 정수, 소수, 분수로 다룰 수 있는 계산을 가능한 한 정확하게 처리합니다. 예를 들어 0.1 + 0.2의 결과는 0.3입니다. 그렇다고 모든 계산에서 오차가 없어지는 것은 아닙니다.

일반 계산의 결과를 확정할 때는 최대 30자리 유효숫자로 정리하며, 값이 바뀌는 끝수 처리가 발생하면 근삿값이 됩니다. 삼각함수와 로그 등의 근사 계산에는 15자리 유효숫자를 기준으로 한 처리가 사용됩니다. π와 e도 유한한 자릿수의 근삿값입니다. 정확한 값과 근삿값의 구분은 재사용할 때도 유지됩니다.

ANS, MR, HISTORY, 프리셋에서 삽입한 괄호로 묶인 녹색 확정값은 보이는 자릿수보다 많은 계산값을 보관할 수 있습니다. 블록 안을 한 글자씩 수정할 수는 없으며 삭제 등은 블록 단위로 처리합니다. 숫자를 바꾸려면 해당 블록을 지우고 다시 입력하세요.

10.2 계산기 표시 설정

  1. 홈 오른쪽 위의 설정 아이콘을 여세요.
  2. “계산기 표시 설정”에서 “소수 자릿수”, “끝수 처리”, “소수점 기호”와 자리 구분 설정을 선택하세요.

소수 자릿수는 0~12자리 중에서 선택할 수 있습니다. 소수점 기호는 점 또는 쉼표, 자리 구분 기호는 없음, 쉼표, 점, 공백 중에서 선택할 수 있으며 3자리 또는 4자리씩 구분할 수 있습니다. 불필요한 끝자리 0은 생략됩니다.

표시를 소수 2자리로 설정하고 1 ÷ 8을 계산하면 0.13으로 보이지만 계산값은 0.125 그대로입니다. ANS × 8의 결과는 1입니다. 표시 설정을 바꾸는 것만으로 ANS, HISTORY, 메모리의 저장값이 바뀌지는 않습니다.

10.3 끝수 처리 방식의 차이

소수 1자리로 처리하는 예입니다.

끝수 처리1.25-1.25
반올림(정확히 중간이면 0에서 멀어지는 쪽)1.3-1.3
내림(작은 쪽으로)1.2-1.3
올림(큰 쪽으로)1.3-1.2

“내림”은 음수의 소수 부분을 단순히 버린다는 뜻이 아닙니다. 또한 round/floor/ceil은 식 안에서 값을 정수로 만드는 함수로, 표시만 바꾸는 설정과 다릅니다.

수식별 “계산 결과 설정”은 값 자체에 끝수 처리를 적용해 확정합니다. 메모리의 덧셈·뺄셈도 매번 최대 30자리 유효숫자로 정리됩니다. 화면에 표시된 값을 직접 입력하면 원래 내부 값과 다른 숫자가 될 수 있다는 점에 주의하세요.

0이 아닌 작은 값이 표시 자릿수 때문에 0이 되면 ≒ 0으로 표시합니다. 큰 값은 지수 표기로 표시될 수도 있습니다. 모든 근삿값에 반드시 ≒가 붙는다는 뜻은 아닙니다.

11. 백업 및 복원

백업과 복원은 PRO 기능입니다. 설정 → “백업 및 복원”에서 여세요.

11.1 포함되는 항목과 제외되는 항목

  • 포함: 수식과 변수 정의, 프리셋, 언어, 화면 모드, 진동, 계산기 표시 설정.
  • 제외: ANS, HISTORY, 메모리, 화면의 Log, 입력 중인 식, 일반 계산기의 함수 설정(DEG/RAD 각도 단위와 함수 패널의 입력 후 자동 닫기 설정).

수식(템플릿)별 각도 단위는 수식 정의에 포함됩니다.

백업은 기기 내 모든 상태를 그대로 복제하는 기능이 아닙니다. 보관할 결과는 HISTORY에서 프리셋에 등록해 두면 프리셋으로 백업할 수 있습니다.

PRO 구매 정보는 App Store 또는 Google Play의 구매 내역으로 관리됩니다. CalcPad 데이터 백업을 복원해도 PRO 구매 자체가 취소되지는 않습니다. 구매했는데 PRO 기능을 사용할 수 없다면 구매할 때와 같은 스토어 계정으로 PRO 화면의 “구매 복원”을 시도하세요.

11.2 백업 만들기

  1. “백업 저장”을 누르세요.
  2. 표시되는 공유 또는 저장 위치를 선택하고 JSON 파일을 저장하세요.
  3. 대상 파일 앱이나 클라우드에서 파일이 실제로 저장되었는지 확인하세요.

11.3 복원하기

  1. 필요하다면 현재 수식, 프리셋, 설정을 먼저 백업하세요.
  2. “백업에서 복원”을 누르세요.
  3. “복원(전체 덮어쓰기)”의 확인 내용을 읽고 “복원하기”를 선택하세요.
  4. 저장해 둔 백업 파일을 선택하세요.
복원은 전체 덮어쓰기입니다

현재 수식, 프리셋, 대상 설정을 파일 내용으로 바꿉니다. 추가하거나 합치는 것이 아니며 되돌릴 수 없습니다. ANS, HISTORY, 메모리는 파일에서 복원되지 않습니다.

이전 형식의 CalcPad 백업도 지원되는 형식이라면 읽을 수 있습니다. 다른 앱의 파일이나 지원되지 않는 형식은 사용할 수 없습니다. 실패하면 표시된 안내를 따르고 파일을 무리하게 수정하지 마세요.

목차로 돌아가기

13. 데이터 저장 및 불러오기 문제

13.1 저장할 수 없을 때

ANS + HISTORY 또는 메모리 저장에 실패하면 홈과 HISTORY의 헤더 바로 아래에 미저장 경고가 표시됩니다. 경고가 표시되는 동안에도 사용할 수 있는 최신 값으로 계산과 기록 조작을 계속할 수 있습니다.

  • “다시 시도”: 저장에 실패한 대상의 최신 내용을 다시 저장합니다.
  • “무시”: 이번 앱 실행 중 해당 대상의 경고를 숨깁니다. 저장 성공을 의미하지 않으며 자동 저장을 중단하는 동작도 아닙니다.

저장되지 않은 상태로 앱을 종료하면 최신 내용이 사라질 수 있습니다. 앱 종료 시 저장 완료는 보장되지 않습니다. 중요한 값이 있다면 경고를 무시한 채 종료하지 않도록 주의하세요.

13.2 ANS, HISTORY, 메모리 불러오기 오류

ANS, HISTORY, 메모리의 저장 데이터에 문제가 있으면 복구용 대화상자가 표시됩니다. 복구 가능한 경우 OK를 누르면 사용할 수 있는 데이터를 우선해 저장 영역을 재구축하고, 복구할 수 없는 내용은 초기화합니다. 지원 범위 밖의 오류는 강제로 초기화하지 않습니다. 표시된 확인 내용을 읽은 뒤 조작하세요.

목차로 돌아가기

14. 이전 버전에서의 데이터 이전과 복구

이 장은 2.0.0 이전 버전부터 CalcPad를 사용하다가 업데이트한 분을 위한 설명입니다. 2.0.0 이상 버전을 처음 설치한 분은 일반적으로 이 장의 작업을 할 필요가 없습니다.

14.1 업데이트 시 데이터 이어받기

기존 프리셋과 수식은 새 형식으로 이전하는 과정을 거쳐 계속 사용할 수 있습니다. 이전 복사 기록은 새로운 HISTORY로 이어지지 않으며 이번 업데이트에서 삭제됩니다. 새로운 HISTORY는 업데이트 후 성공한 계산부터 기록합니다.

14.2 기존 프리셋과 수식을 새 형식으로 이전하지 못했을 때

해당 프리셋 목록 또는 수식 목록에 데이터 이전 오류 안내가 표시될 수 있습니다. 기존 데이터를 새 형식으로 옮기는 데 실패한 뒤에도 안전하게 다시 시작할 수 있다고 확인된 경우에만 다음 작업을 이용할 수 있습니다.

  1. 다시 시도: 먼저 원래 데이터를 사용해 데이터 이전을 다시 시도합니다.
  2. 샘플로 다시 시작: 문제가 있는 그룹만 샘플로 바꿉니다. 프리셋은 3개, 수식은 2개로 시작합니다.
  3. 빈 상태로 다시 시작: 문제가 있는 그룹만 0개로 만들어 새로 등록할 수 있는 상태로 만듭니다.

뒤의 두 작업에서는 대상과 개수 등의 확인 내용을 읽고 “이전 데이터 삭제 후 시작”을 눌러야 삭제가 실행됩니다. 취소하면 실행되지 않습니다.

삭제한 이전 데이터는 되돌릴 수 없습니다

대상 그룹의 이전 데이터를 삭제합니다. 다른 그룹과 설정은 변경하지 않습니다. 보관할 내용이 있다면 삭제하지 말고 상황을 확인하세요.

일시적인 읽기·쓰기 장애나 알 수 없는 형식처럼 원인이나 삭제 범위를 안전하게 판단할 수 없는 경우에는 삭제 작업을 사용할 수 없습니다. 모든 저장 장애에 사용할 수 있는 초기화 버튼은 아닙니다. 다시 시도하거나 앱을 재시작하고 안내를 확인하세요.

“새 데이터는 사용할 수 있습니다. 이전 데이터 정리는 대기 중이며 다음 실행 시 안전하게 재시도합니다.”가 표시되면 다음 실행 시 안전하게 정리를 다시 시도합니다.

15. 설정과 사용 시 주의 사항

15.1 언어, 화면 모드, 진동

설정 화면에서 언어, 화면 모드, 버튼 조작 시 진동을 바꿀 수 있습니다. 언어는 일본어, 영어, 프랑스어, 한국어, 스페인어를 지원하며 화면 모드는 시스템, 라이트, 다크 중에서 선택할 수 있습니다. 소수점과 자리 구분 표시는 “계산기 표시 설정”도 확인하세요.

15.2 샘플을 다시 가져오는 경우

설정의 “샘플 데이터 가져오기”는 현재 프리셋과 수식을 모두 샘플로 바꿉니다. 설정은 변경하지 않습니다. 첫 실행 시 가져오기나 데이터 이전 오류 시 한 그룹만 다시 시작하는 작업과는 다릅니다. 확인 화면을 읽고 실행하세요.

15.3 입력 오류와 계산 한계

  • 괄호와 절댓값 구분 기호는 닫으세요. sin(30과 같은 미완성 식은 계산할 수 없습니다.
  • 1 ÷ 0, √(-1), log(0)처럼 처리할 수 없는 계산이 있습니다.
  • 숫자의 크기나 식의 복잡성에 따라 안전 제한으로 계산 또는 저장이 불가능할 수 있습니다.
  • 근사 계산이나 끝수 처리가 적용된 결과를 무한 정밀도의 정확한 값으로 생각하지 마세요. 중요한 용도로 사용할 때는 입력, 단위, 끝수 처리, 결과를 확인하세요.

15.4 데이터 보호하기

앱을 제거하면 기기에 저장된 데이터가 사라집니다. 백업 대상인 수식, 프리셋, 설정은 PRO에서 정기적으로 파일에 저장하고 저장 위치도 확인하세요. ANS, HISTORY, 메모리는 백업에 포함되지 않으므로 중요한 기록을 여기에만 의존하지 마세요.
