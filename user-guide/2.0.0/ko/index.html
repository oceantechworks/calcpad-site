1. CalcPad로 할 수 있는 일

CalcPad는 일반 계산기처럼 사용할 수 있을 뿐 아니라, 자주 쓰는 숫자와 수식을 저장해 필요할 때 다시 불러올 수 있는 앱입니다. 이 가이드에서는 저장한 수식을 ‘수식(템플릿)’이라고 부르기도 합니다.

  • 사칙연산, 괄호, 퍼센트, 거듭제곱으로 계산하기
  • ANS로 직전 결과를, HISTORY에서 이전 결과를 불러오기
  • 메모리에 값을 더하거나 빼서 합계 구하기
  • 자주 쓰는 숫자는 프리셋으로, 반복하는 계산 절차는 수식으로 저장하기
  • 함수와 상수 사용하기(일부 함수와 백업·복원 기능은 PRO가 필요합니다)

먼저 일반 계산을 해 보세요. 그런 다음 ANS나 HISTORY로 결과를 다시 불러올 수 있습니다.

처음 실행할 때 샘플 가져오기

첫 실행 시 “샘플 데이터를 불러오시겠습니까?”가 표시되면 “가져오기”를 선택해 수식 2개와 프리셋 3개를 가져올 수 있습니다. “가져오지 않기”를 선택해 빈 상태로 시작할 수도 있습니다. 두 방법 모두 Free에서 이용할 수 있습니다.

샘플에는 BMI 등의 수식과 cm / 인치, 표준 중력 가속도 g, 황금비 φ 프리셋이 들어 있습니다. 가져온 샘플은 나중에 편집하거나 삭제할 수 있습니다.

2. 일반 계산기로 사용하기

2.1 입력하고 계산하기

  1. 숫자와 연산자를 순서대로 누릅니다. 예를 들어 1200 × 5 × 80%을 입력해 보세요.
  2. =(아래쪽 표시는 ENTER)를 누르세요.
  3. 계산식과 결과 4800이 화면의 Log에 표시됩니다.

80%는 0.8을 의미합니다. 200 + 10%의 결과는 200.1입니다. 200에 10%를 더하려면 200 × (1 + 10%)로 입력하세요.

2.2 입력 수정하기

  • 입력 줄을 누르면 원하는 위치로 커서를 옮길 수 있습니다. ◀/▶로도 좌우로 이동할 수 있습니다.
  • ⌫는 커서 바로 앞의 내용을 삭제합니다.
  • C/AC를 짧게 누르면 입력 중인 식을 지울 수 있습니다. 일반 계산기 화면에서 길게 누르면 입력 중인 식과 화면의 Log를 함께 지울 수 있습니다.
  • C/AC로는 ANS, HISTORY, 메모리가 지워지지 않습니다.

2.3 괄호, 거듭제곱, 이어서 계산하기

(2 + 3) × 4 = 20, 2 ^ 3 = 8과 같이 입력할 수 있습니다. 곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 계산됩니다. 결과를 사용해 다른 계산을 하려면 ANS를 이용하면 값을 다시 입력하지 않아도 됩니다.

2.4 Log 재사용하기

Log에는 현재 화면에서 진행한 계산 과정이 표시됩니다. 계산이 끝난 계산식 줄을 길게 누르면 해당 식을 입력 줄의 커서 위치에 넣을 수 있습니다. 예를 들어 100×1.1+500을 다시 불러와 100을 200으로 바꾼 뒤 계산할 수 있습니다.

계산 결과 줄을 길게 누르면 결과가 괄호로 묶인 확정값으로 삽입됩니다. 화면에 숫자가 반올림되어 보이더라도 원래 계산값을 그대로 재사용할 수 있습니다. 수식(템플릿)에서 입력을 확정한 변수 줄도 길게 누를 수 있으며, 변수 이름과 단위를 뺀 숫자만 삽입됩니다.

길게 누른 내용은 기기의 클립보드가 아니라 CalcPad의 입력 줄에 들어갑니다. 필요한 내용을 추가하거나 수정한 다음 =를 누르면 계산할 수 있습니다. Log를 지워도 HISTORY에 저장된 기록은 남습니다.

목차로 돌아가기

3. ANS 사용하기

ANS에는 가장 최근에 정상적으로 완료한 계산 결과가 하나 저장됩니다. 일반 계산과 저장된 수식을 끝까지 실행한 최종 결과가 해당됩니다. 계산에 실패하거나 수식의 변수를 입력하는 중에는 이전 ANS 값이 그대로 남습니다.

3.1 직전 결과 불러오기

  1. 12 × 8을 입력하고 =를 눌러 96을 구하세요.
  2. ANS를 짧게 누르세요. 커서 위치에 괄호로 묶인 녹색 값이 삽입됩니다.
  3. 이어서 ÷ 3을 입력하고 =를 누르면 32가 됩니다.

ANS를 누르면 그때 저장되어 있는 값이 입력 줄에 삽입됩니다. 이후 ANS가 바뀌어도 이미 삽입한 값은 달라지지 않습니다. 화면에서 자릿수가 생략되거나 반올림되어 보여도 저장된 계산값을 사용할 수 있습니다.

3.2 보관, 갱신, 지우기

  • ANS에 아직 결과가 없으면 짧게 눌러도 값이 입력되지 않습니다. 계산 결과가 0이라면 0도 정상적으로 저장됩니다.
  • 정상적으로 저장된 ANS 값은 앱을 다시 실행한 뒤에도 남아 있습니다.
  • 새 계산이 정상적으로 완료되면 ANS는 그 결과로 바뀝니다. ANS만 따로 지우는 버튼은 없습니다.
  • HISTORY 삭제나 MC로는 ANS가 지워지지 않습니다. 백업에는 포함되지 않습니다.

ANS를 길게 누르면 HISTORY가 열립니다. 짧게 누르면 ANS 값이 입력됩니다.

목차로 돌아가기

4. HISTORY 사용하기

HISTORY에는 정상적으로 끝난 계산의 식과 결과가 자동으로 기록됩니다. 최대 30개까지 저장되며, 한도를 넘으면 오래된 기록부터 삭제됩니다. 일반 계산과 저장된 수식의 최종 결과가 대상입니다. 변수 입력 중간에 나온 값이나 단순히 값을 삽입한 동작은 기록되지 않습니다.

HISTORY에는 계산할 때 표시된 식이 그대로 남습니다. 나중에 소수 자릿수, 끝수 처리, 소수점 기호, 자리 구분 기호, 앱 언어를 바꿔도 기록한 식은 바뀌지 않습니다. 수식(템플릿)은 실행 당시의 변수값을 대입한 식과 당시 수식 이름을 표시합니다.

예를 들어 소수점 이하 6자리와 반올림을 설정한 상태에서 1÷3을 계산하면 0.333333으로 표시됩니다. 이어서 ANS를 불러와 (0.333333)×3을 계산하면 결과는 1입니다. HISTORY에는 식이 각각 1÷3과 (0.333333)×3으로 남습니다. 내부에 저장된 긴 숫자로 바뀌거나 표시용 반올림만으로 ≒ 기호가 추가되지는 않습니다. 다만 0이 아닌 값이 화면에서 0으로 보이면 ≒ 0 표시는 유지됩니다.

HISTORY의 결과는 계산할 때의 소수 자릿수와 끝수 처리 방식으로 표시됩니다. 소수점과 자리 구분 기호만 현재 설정을 따릅니다. 화면에 식이나 결과가 반올림되어 보이더라도 저장된 계산값까지 그 자릿수로 줄어드는 것은 아닙니다. 다시 불러올 때는 저장된 고정밀 값을 사용할 수 있습니다.

4.1 이전 결과 불러오기

  1. 홈의 ANS를 길게 누르세요. 키 아래쪽의 HISTORY 표시를 확인하세요.
  2. 최신 기록은 목록 아래에 있습니다. 위로 스크롤하면 오래된 기록을 확인할 수 있습니다.
  3. 사용할 항목의 계산식 영역이나 결과 영역을 누르세요.
  4. 값이 삽입되면 계산기 화면으로 돌아가며, 커서 위치에 괄호로 묶인 확정값이 표시됩니다.

HISTORY에서 불러오는 것은 저장된 결과입니다. 기록된 식을 편집 가능한 상태로 불러오거나 다시 계산하는 기능은 아닙니다. 결과를 삽입하는 것만으로는 ANS, HISTORY, Log, 메모리가 바뀌지 않습니다.

4.2 각 항목의 동작

조작동작
M+/M-해당 항목의 결과를 메모리에 더하거나 뺍니다. 홈의 M+/M-와는 사용하는 값이 다릅니다.
점 3개 메뉴 → 프리셋에 등록결과값을 유지한 채 이름을 붙여 저장합니다. 수식 기록에서는 수식 이름이 초기 이름이 됩니다.
점 3개 메뉴 → OS에 복사결과의 숫자를 기기의 클립보드에 복사해 다른 앱에 붙여 넣을 수 있습니다. 식 전체를 복사하는 기능은 아닙니다.
점 3개 메뉴 → 삭제해당 기록을 삭제합니다.

4.3 전체 삭제와 보관

모든 기록을 지우려면 화면 위쪽의 전체 삭제 버튼을 누르고 “모든 기록을 삭제할까요?”를 확인한 다음 “지우기”를 선택합니다. 삭제한 기록은 복구할 수 없으므로 내용을 확인한 뒤 진행해 주세요. 일부 기록만 삭제하거나 전부 삭제해도 ANS와 메모리는 바뀌지 않습니다.

HISTORY가 정상적으로 저장되었다면 다음에 앱을 열었을 때도 사용할 수 있습니다. 백업에는 포함되지 않습니다. 저장에 문제가 있을 때는 데이터 저장 및 불러오기 문제를 참고해 주세요.

목차로 돌아가기

5. 메모리 사용하기

메모리 기능을 사용하면 여러 계산 결과를 더하거나 빼면서 합계를 저장할 수 있습니다. 처음 값은 0이며, 홈 화면 위쪽과 HISTORY 맨 아래에 M = …로 표시됩니다.

키홈에서의 동작
MC메모리를 정확한 0으로 되돌립니다.
MR현재 메모리 값을 커서 위치에 삽입합니다. 메모리는 지우지 않습니다.
M+마지막으로 성공한 계산 결과(ANS)를 더합니다.
M-마지막으로 성공한 계산 결과(ANS)를 뺍니다.

5.1 100과 30을 더하는 예

  1. MC로 메모리를 0으로 만드세요.
  2. 100을 입력하고 =, M+ 순서로 누르세요. 메모리가 100이 됩니다.
  3. 30을 입력하고 =, M+ 순서로 누르세요. 메모리가 130이 됩니다.
  4. MR로 130을 입력 줄에 불러올 수 있습니다. ANS가 여전히 30일 때 M-를 누르면 메모리는 100이 됩니다.
M+/M-의 대상에 주의하세요

홈 화면의 M+와 M-는 입력 중인 숫자가 아니라 ANS에 저장된 결과를 사용합니다. 예를 들어 100을 입력하기만 하고 M+를 눌러도 100이 더해지는 것은 아닙니다. 100을 더하려면 먼저 =로 계산을 완료해 주세요. ANS에 결과가 없으면 메모리는 바뀌지 않습니다. 수식의 변수를 입력하는 중에도 M+/M-는 마지막으로 완료한 결과를 사용합니다.

5.2 HISTORY에서 조작하기

각 기록 항목의 M+/M-는 해당 항목의 결과를 사용합니다. 맨 아래 M = … 표시에서 MC 왼쪽을 누르면 MR과 같이 값을 삽입하고 계산기로 돌아갑니다. MC는 메모리만 0으로 만들고 HISTORY 화면을 유지합니다.

메모리에 값을 더하거나 빼고 MC로 지워도 입력 중인 식, ANS, HISTORY는 바뀌지 않습니다. MR은 메모리 값을 입력 줄에 넣는 기능이므로, 그것만으로 새 계산 기록이 생기지는 않습니다. 정상적으로 저장되었다면 앱을 다시 실행해도 메모리는 남지만, 백업에는 포함되지 않습니다. M = —가 표시되면 메모리를 사용할 수 없는 상태이며, 값이 0인 경우와는 다릅니다.

목차로 돌아가기

6. 프리셋 사용하기

프리셋에는 단가, 세율, 환산 계수처럼 자주 쓰는 숫자를 이름과 함께 저장할 수 있습니다. 메모리에서 합계를 계산하는 것과 달리, 같은 숫자를 여러 번 불러올 때 편리합니다.

6.1 등록하기

  1. PRE로 “프리셋”을 여세요.
  2. 오른쪽 위의 ＋로 추가하세요.
  3. 값과 필요한 경우 라벨을 입력하고 저장하세요. 예: 라벨 “시급”, 값 1500.

계산 결과를 프리셋으로 남기려면 HISTORY의 점 3개 메뉴에서 “프리셋에 등록”을 선택합니다. 화면에 반올림되어 표시된 숫자를 직접 다시 입력할 필요가 없습니다. 결과값이 그대로 저장되며 이름도 바꿀 수 있습니다.

6.2 불러오기와 편집

  • PRE를 열고 항목을 누르면 커서 위치에 괄호로 묶인 녹색 확정값이 삽입됩니다.
  • 각 항목의 점 3개 메뉴에서 “편집”, “삭제”를 선택하세요.
  • “순서 변경”을 선택한 뒤 항목을 드래그해 순서를 바꾸고, “완료”를 눌러 일반 표시로 돌아가세요.

Free는 최대 5개입니다. 첫 실행 시 가져온 샘플 3개도 개수에 포함됩니다. 현재 샘플에는 “cm / 인치: 2.54”, “표준 중력 가속도 g: 9.80665”, “황금비 φ: 1.618”이 있습니다. 원주율 π는 프리셋이 아니라 FUNC에서 입력할 수 있습니다.

프리셋은 백업에 포함됩니다. 앱의 샘플이 업데이트되더라도 이미 저장해 둔 프리셋은 자동으로 바뀌지 않습니다.

목차로 돌아가기

7. 수식 만들기

자주 하는 계산은 수식으로 저장해 두면 편리합니다. 다음부터는 단가나 수량처럼 달라지는 값만 입력하면 됩니다. 여기서는 “단가 × 수량 × 1.1”을 만들어 보겠습니다.

  1. ƒ(x)로 “수식”을 열고 오른쪽 위의 ＋를 누르세요.
  2. “기본 정보”의 “수식 이름(필수)”에 “세금 포함 합계” 등의 이름을 입력하세요. 설명은 선택 사항입니다.
  3. “계산 결과 설정”에서 결과 이름, 소수 자릿수, 끝수 처리를 선택하세요.
  4. “변수”의 추가 버튼으로 숫자 타입의 “단가”(키 a)와 “수량”(키 b)을 등록하세요.
  5. “수식” 입력 영역에서 변수 버튼, 연산자, 숫자를 사용해 a × b × 1.1을 만드세요.
  6. “저장”을 누르세요.

7.1 변수란?

변수는 수식을 사용할 때마다 값을 입력하는 항목입니다. 예를 들어 변수 이름을 “단가”, 식에서 쓰는 키를 a로 정할 수 있습니다. 초기값을 지정하면 입력할 때 후보로 표시됩니다. 수식을 저장하려면 변수를 한 개 이상 만들고, 그중 적어도 하나를 식에 사용해야 합니다. 만든 변수를 모두 사용할 필요는 없습니다.

변수 타입은 “숫자” 또는 “%”(퍼센트) 중에서 고릅니다. 퍼센트 변수는 식에 a%처럼 들어갑니다. 수식을 실행할 때 10을 입력하면 10%로 계산되므로, 식에서 다시 100으로 나눌 필요는 없습니다.

소문자 e는 네이피어 수로 예약되어 있어 변수 키로 사용할 수 없습니다.

7.2 함수, 끝수 처리, 편집

수식 작성 화면의 함수 버튼은 “Func”입니다. E, π, e는 Free에서도 사용할 수 있고 다른 함수는 PRO에서 이용할 수 있습니다. 삼각함수의 각도 단위는 수식별로 저장합니다.

수식의 결과는 지정한 소수 자릿수로 확정됩니다

“계산 결과 설정”에서 선택한 소수 자릿수와 끝수 처리 방식은 수식의 최종 계산값 자체에 적용됩니다. 홈 화면에서 보이는 자릿수만 바꾸는 설정과는 다릅니다. ANS와 HISTORY에도 이렇게 확정된 값이 저장됩니다.

수식 목록의 점 3개 메뉴에서 수식을 편집하거나 삭제할 수 있습니다. “순서 변경”으로 위치도 바꿀 수 있습니다. 수식에 사용 중인 변수를 지우려면 먼저 식에서 해당 변수를 제거해 주세요. 삭제한 내용은 복구할 수 없으므로 확인한 뒤 진행하는 것이 좋습니다.

목차로 돌아가기

8. 저장한 수식 실행하기

  1. ƒ(x)로 수식 목록을 열고 사용할 수식을 누르세요.
  2. 표시된 변수의 값을 입력하고 =/ENTER로 확정하세요.
  3. 다음 변수가 표시되면 같은 방법으로 입력하고 확정하세요.
  4. 마지막 변수를 확정하면 결과가 표시됩니다.

“단가 × 수량 × 1.1”에 단가 1200, 수량 3을 입력하면 결과는 3960입니다.

[단가] = 1200
[수량] = 3
[결과] = 3960

변수 값을 입력할 때도 1200 × 2와 같은 계산을 하거나 ANS, MR, 프리셋, HISTORY에서 값을 불러올 수 있습니다. 다만 최종 결과가 표시된 뒤처럼 입력할 수 없는 상태에서는 값을 삽입할 수 없습니다.

수식을 끝까지 실행해 정상적으로 결과가 나오면 ANS에 저장되고, 수식 이름과 함께 HISTORY에도 기록됩니다. 변수를 일부만 입력한 상태에서는 ANS가 바뀌지 않습니다. 입력을 중단하고 일반 계산기로 돌아가려면 C/AC를 길게 누릅니다.

9.1 지수 표기 E와 상수 π, e

  • 1.2E3은 1.2 × 10^3 = 1200을 의미하며, 1.2E-3의 값은 0.0012입니다. 숫자 뒤에 E를 입력하고 지수를 이어 입력합니다. E만 있거나 지수가 끝나지 않은 식은 계산할 수 없습니다.
  • π는 원주율입니다. 반지름이 5인 원의 넓이는 π × 5 ^ 2로 구하며 약 78.539816입니다(소수 6자리 표시 예).
  • 소문자 e는 네이피어 수로 약 2.718282입니다. 대문자 E를 사용하는 지수 표기와는 다릅니다.

9.3 min/max와 쉼표

min과 max에는 값이 두 개 이상 필요합니다. 일반 계산기에서 커서가 min 또는 max의 인수 안에 있으면 화면 오른쪽 아래에 , NEXT ARG가 나타납니다. 구분 기호를 넣을 수 있는 위치에서 누르면 쉼표와 공백이 입력됩니다. 저장할 수식을 만들 때는 수식 빌더의 쉼표 버튼을 사용합니다.

여기서 쉼표는 함수에 넣는 값들을 구분하는 기호이며, 숫자의 자리 구분 기호와는 다릅니다. 예를 들어 max(100, 200)처럼 입력합니다. max(100, )처럼 마지막 값이 빠진 식은 아직 계산할 수 없습니다.

9.4 활용 예제

물건이 13개이고 한 상자에 6개씩 들어간다면, ceil(13 ÷ 6) = 3을 이용해 필요한 상자 수를 구할 수 있습니다.

기본 보수가 3600이고, 10km를 초과한 거리만 1km당 100을 더하는 경우에는 3600 + 100 × max(0, a - 10)로 계산할 수 있습니다(a는 거리). a가 8이면 3600, 15이면 4100입니다.

가격에서 20%를 할인하되 할인액을 최대 1000으로 제한하려면 min(a × 20%, 1000)로 계산할 수 있습니다(a는 가격). 가격이 3000이면 할인액은 600, 8000이면 1000입니다.

9.5 각도 단위와 입력 후 동작

일반 계산기에서는 함수 시트에서 DEG(도) 또는 RAD(라디안)를 선택할 수 있습니다. 삼각함수가 포함된 식을 입력하면 홈 화면 위쪽에 DEG/RAD가 표시됩니다. 저장한 수식은 각 수식에 설정된 각도 단위를 사용하므로 일반 계산기의 설정과는 별개입니다.

“입력 후 자동으로 닫기”는 Free와 PRO에서 모두 사용할 수 있습니다. 일반 계산기에서 ON으로 설정하면 입력에 성공했을 때 함수 시트가 닫히고, OFF로 설정하면 열린 상태로 유지됩니다. 수식 빌더의 함수 시트는 입력에 성공하면 닫힙니다.

목차로 돌아가기

10. 계산 정밀도와 표시 설정

10.1 계산값과 화면 표시값은 다릅니다

CalcPad는 정수, 소수, 분수로 표현할 수 있는 계산을 최대한 정확하게 처리합니다. 예를 들어 0.1 + 0.2의 결과는 0.3입니다. 다만 계산 종류에 따라 근삿값이 사용될 수 있습니다.

일반 계산을 마치면 결과는 최대 30자리의 유효숫자로 정리됩니다. 반올림 등으로 값이 달라지면 근삿값으로 취급합니다. 삼각함수와 로그 함수는 유효숫자 15자리를 기준으로 근사 계산하며, π와 e도 제한된 자릿수로 나타낸 근삿값입니다. 결과를 다시 사용할 때도 정확한 값과 근삿값의 구분은 유지됩니다.

ANS, MR, HISTORY, 프리셋에서 불러온 초록색 괄호 속 확정값에는 화면에 표시된 것보다 더 많은 자릿수가 저장되어 있을 수 있습니다. 일반적인 십진수 표기로 표시된 확정값은 블록 안의 숫자를 직접 수정할 수 있습니다. 수정하면 초록색 표시와 자동으로 추가된 괄호가 해제되어 일반 입력값으로 바뀝니다. 이때 원래 확정값에 저장되어 있던 화면에 표시되지 않은 자릿수는 유지되지 않습니다. 지수 표기(E)나 '≒' 기호가 포함된 확정값은 내부 숫자를 수정할 수 없습니다. 값을 바꾸려면 블록 전체를 삭제한 뒤 다시 입력하세요.

10.2 계산기 표시 설정

  1. 홈 오른쪽 위의 설정 아이콘을 여세요.
  2. “계산기 표시 설정”에서 “소수 자릿수”, “끝수 처리”, “소수점 기호”와 자리 구분 설정을 선택하세요.

소수점 이하 자릿수는 0~12자리에서 고를 수 있습니다. 소수점 기호는 점 또는 쉼표를, 자리 구분 기호는 없음·쉼표·점·공백을 선택할 수 있습니다. 숫자는 3자리 또는 4자리마다 구분할 수 있으며, 끝에 붙은 불필요한 0은 표시되지 않습니다.

예를 들어 소수점 이하 2자리로 설정하고 1 ÷ 8을 계산하면 화면에는 0.13으로 표시됩니다. 하지만 계산값은 0.125 그대로이므로 ANS × 8의 결과는 1입니다. 표시 설정을 바꾸어도 ANS, HISTORY, 메모리에 저장된 값은 변하지 않습니다.

10.3 끝수 처리 방식의 차이

소수 1자리로 처리하는 예입니다.

끝수 처리1.25-1.25
반올림(정확히 중간이면 0에서 멀어지는 쪽)1.3-1.3
내림(작은 쪽으로)1.2-1.3
올림(큰 쪽으로)1.3-1.2

음수에서 “내림”을 선택하면 더 작은 수 쪽으로 끝수 처리가 적용됩니다. 소수 부분만 없애는 것과는 다릅니다. 또한 round, floor, ceil은 식 안의 값을 정수로 만드는 함수로, 화면의 표시만 바꾸는 설정과는 다릅니다.

수식별 “계산 결과 설정”은 수식이 끝날 때 계산값 자체를 반올림 등으로 확정합니다. 메모리에 값을 더하거나 뺄 때도 매번 최대 30자리 유효숫자로 정리됩니다. 화면에 반올림되어 보이는 숫자를 직접 다시 입력하면 원래 계산값과 달라질 수 있습니다.

0이 아닌 작은 값이 표시 자릿수 때문에 0으로 보이면 ≒ 0으로 표시됩니다. 아주 큰 값은 지수 표기로 보일 수 있습니다. 다만 모든 근삿값에 ≒ 기호가 붙는 것은 아닙니다.

11. 백업 및 복원

백업과 복원은 PRO 기능입니다. 설정 → “백업 및 복원”에서 여세요.

11.1 포함되는 항목과 제외되는 항목

  • 포함: 수식과 변수 정의, 프리셋, 언어, 화면 모드, 진동, 계산기 표시 설정.
  • 제외: ANS, HISTORY, 메모리, 화면의 Log, 입력 중인 식, 일반 계산기의 함수 설정(DEG/RAD 각도 단위와 함수 패널의 입력 후 자동 닫기 설정).

수식(템플릿)별 각도 단위는 수식 정의에 포함됩니다.

백업에 포함되지 않는 데이터도 있습니다. 계산 결과를 남겨 두고 싶다면 HISTORY에서 프리셋으로 등록해 주세요. 그러면 프리셋으로 백업할 수 있습니다.

PRO 구매 정보는 App Store 또는 Google Play에서 관리합니다. CalcPad의 데이터 백업을 복원해도 PRO 구매 내역에는 영향을 주지 않습니다. PRO를 구매했는데 기능을 사용할 수 없다면 구매할 때 사용한 스토어 계정으로 로그인한 뒤 PRO 화면에서 “구매 복원”을 시도해 보세요.

11.2 백업 만들기

  1. “백업 저장”을 누르세요.
  2. 표시되는 공유 또는 저장 위치를 선택하고 JSON 파일을 저장하세요.
  3. 대상 파일 앱이나 클라우드에서 파일이 실제로 저장되었는지 확인하세요.

11.3 복원하기

  1. 필요하다면 현재 수식, 프리셋, 설정을 먼저 백업하세요.
  2. “백업에서 복원”을 누르세요.
  3. “복원(전체 덮어쓰기)”의 확인 내용을 읽고 “복원하기”를 선택하세요.
  4. 저장해 둔 백업 파일을 선택하세요.
복원은 전체 덮어쓰기입니다

백업을 복원하면 현재 수식, 프리셋, 해당 설정이 파일의 내용으로 바뀝니다. 기존 데이터에 추가하거나 합치는 방식이 아니며, 복원 후에는 되돌릴 수 없습니다. ANS, HISTORY, 메모리는 이 파일에서 복원되지 않습니다.

이전 버전에서 만든 CalcPad 백업도 지원되는 형식이라면 읽을 수 있습니다. 다른 앱에서 만든 파일이나 지원되지 않는 형식은 복원할 수 없습니다. 복원에 실패했다면 화면에 표시된 안내를 확인해 주세요. 백업 파일을 직접 수정하는 것은 피하는 것이 좋습니다.

샘플도 Free의 등록 개수 제한에 포함됩니다. PRO에서는 등록 개수 제한이 없어지지만, 안전을 위해 수식 길이나 숫자 크기 등에 대한 제한은 유지됩니다. PRO로 바꿔도 계산 정밀도는 달라지지 않습니다.

PRO 화면에서 구매하거나 구매 내역을 복원할 수 있습니다. 운영체제나 앱 스토어가 다른 기기로 옮기는 경우에는 구매 정보가 자동으로 이전되지 않을 수 있습니다.

목차로 돌아가기

13. 데이터 저장 및 불러오기 문제

13.1 저장할 수 없을 때

ANS + HISTORY 또는 메모리를 저장하지 못하면 홈 화면과 HISTORY 화면의 상단에 미저장 경고가 나타납니다. 경고가 표시되는 동안에도 사용할 수 있는 최신 값으로 계산하거나 기록을 확인할 수 있습니다.

  • “다시 시도”: 저장에 실패한 대상의 최신 내용을 다시 저장합니다.
  • “무시”: 앱을 다시 시작할 때까지 해당 데이터의 경고를 숨깁니다. 데이터가 저장되었다는 뜻은 아니며, 자동 저장은 계속 진행됩니다.

변경한 내용이 저장되기 전에 앱을 닫으면 최신 값이 사라질 수 있습니다. 앱이 종료될 때 저장이 항상 완료되는 것은 아닙니다. 중요한 값이 있다면 경고가 표시되는 동안 “다시 시도”를 눌러 저장할 수 있는지 확인해 주세요.

13.2 ANS, HISTORY, 메모리 불러오기 오류

ANS, HISTORY 또는 메모리의 저장 데이터를 읽는 데 문제가 있으면 복구 대화상자가 나타납니다. 복구할 수 있는 경우 OK를 누르면 사용 가능한 데이터를 최대한 남기면서 저장 영역을 다시 구성합니다. 복구할 수 없는 데이터는 초기화됩니다. 지원하지 않는 오류에서는 강제로 초기화하지 않습니다. 진행하기 전에 안내 내용을 확인해 주세요.

목차로 돌아가기

14. 이전 버전에서의 데이터 이전과 복구

이 장에서는 2.0.0보다 이전 버전에서 업데이트할 때 데이터가 어떻게 처리되는지 설명합니다. 2.0.0 이상 버전의 CalcPad를 처음 설치했다면 일반적으로 이 단계가 필요하지 않습니다.

14.1 업데이트 시 데이터 이어받기

업데이트할 때 기존 프리셋과 수식은 새로운 형식으로 옮겨집니다. 이전 작업이 정상적으로 완료되면 계속 사용할 수 있습니다. 이전 복사 기록은 새로운 HISTORY로 이어지지 않으며 이번 업데이트에서 삭제됩니다. 새로운 HISTORY에는 업데이트 후 정상적으로 완료된 계산부터 기록됩니다.

14.2 기존 프리셋과 수식을 새 형식으로 이전하지 못했을 때

프리셋이나 수식을 새 형식으로 옮기지 못한 경우 해당 목록에 오류 안내가 나타날 수 있습니다. CalcPad가 안전하게 다시 시작할 수 있다고 확인한 경우에만 다음 작업을 선택할 수 있습니다.

  1. 다시 시도: 먼저 원래 데이터를 사용해 데이터 이전을 다시 시도합니다.
  2. 샘플로 다시 시작: 문제가 있는 그룹(프리셋 또는 수식)만 샘플로 바꿉니다. 프리셋 3개 또는 수식 2개로 다시 시작할 수 있습니다.
  3. 빈 상태로 다시 시작: 문제가 있는 그룹(프리셋 또는 수식)만 비워 새 항목을 등록할 수 있도록 합니다.

마지막 두 작업을 선택하면 확인 대화상자에서 대상 그룹과 항목 수를 볼 수 있습니다. “이전 데이터 삭제 후 시작”을 누르기 전에는 데이터가 삭제되지 않습니다. 취소하면 기존 데이터가 그대로 남습니다.

삭제한 이전 데이터는 복구할 수 없습니다

문제가 있는 그룹의 기존 프리셋 또는 수식만 삭제됩니다. 다른 그룹의 데이터와 설정은 그대로 남습니다. 보관하고 싶은 내용이 있다면 삭제를 선택하기 전에 상황을 확인해 주세요.

CalcPad가 오류 원인이나 삭제될 데이터의 범위를 안전하게 판단할 수 없는 경우에는 삭제 옵션을 사용할 수 없습니다. 일시적인 읽기·쓰기 오류나 알 수 없는 데이터 형식에서 이런 상황이 발생할 수 있습니다. 이 기능으로 모든 저장 문제를 해결할 수 있는 것은 아닙니다. 화면의 안내에 따라 다시 시도하거나 앱을 재시작해 보세요.

“새 데이터는 사용할 수 있습니다. 이전 데이터 정리는 대기 중이며 다음 실행 시 안전하게 재시도합니다.”라는 메시지가 나오면, 다음에 앱을 실행할 때 남은 정리 작업을 다시 시도합니다.

15. 설정과 사용 시 주의 사항

15.1 언어, 화면 모드, 진동

설정 화면에서 언어, 화면 모드, 버튼 조작 시 진동을 바꿀 수 있습니다. 언어는 일본어, 영어, 프랑스어, 한국어, 스페인어를 지원하며 화면 모드는 시스템, 라이트, 다크 중에서 선택할 수 있습니다. 소수점과 자리 구분 표시는 “계산기 표시 설정”도 확인하세요.

15.2 샘플을 다시 가져오는 경우

설정의 “샘플 데이터 가져오기”를 사용하면 현재 프리셋과 수식이 모두 샘플로 바뀝니다. 설정은 그대로 유지됩니다. 처음 실행할 때 샘플을 가져오거나 이전 오류가 난 그룹 하나만 다시 시작하는 것과는 다른 작업이므로, 확인 화면을 살펴본 뒤 진행해 주세요.

15.3 입력 오류와 계산 한계

  • 계산하려면 괄호와 절댓값 구분 기호를 닫아야 합니다. 예를 들어 sin(30처럼 끝나지 않은 식은 아직 계산할 수 없습니다.
  • 1 ÷ 0, √(-1), log(0)처럼 처리할 수 없는 계산이 있습니다.
  • 숫자의 크기나 식의 복잡성에 따라 안전 제한으로 계산 또는 저장이 불가능할 수 있습니다.
  • 근사 계산이나 끝수 처리를 거친 결과에는 정밀도에 한계가 있습니다. 중요한 용도로 사용할 때는 입력값, 단위, 끝수 처리 방식, 계산 결과를 확인해 주세요.

15.4 데이터 보호하기

CalcPad를 삭제하면 기기에 저장된 데이터도 사라집니다. 수식, 프리셋, 설정을 보관하려면 PRO 백업 기능을 사용해 정기적으로 파일로 저장하고, 파일이 원하는 위치에 있는지 확인해 두면 좋습니다. ANS, HISTORY, 메모리는 백업에 포함되지 않습니다. 중요한 계산 결과는 HISTORY에서 프리셋으로 등록해 두면 백업할 수 있습니다.
